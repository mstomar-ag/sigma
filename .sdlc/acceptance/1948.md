## Done when
- [ ] Filing, triage and promote detect an issue that looks like an epic (a title that starts with `EPIC`, a body with a child or slice list, or the configured tier label) and add the upper-tier label, or refuse to arm it and say why.
- [ ] The doctor lists open issues that look like epics but carry no upper-tier label (bounded, with a count of the rest).
- [ ] Optional: a config key names the repository's epic label; default `epic`.
- [ ] Tests: `promote.py apply` refuses an unlabelled epic-shaped issue, and the doctor row lists it; each goes red when its detection is removed.
