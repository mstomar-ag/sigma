## Done when
- [ ] After a successful save, the refresher writes `dag/map.json` in the ledger worktree (schema `dag/1`, the same numbers-only filter as `dag_store.save`, atomic), and `sync.publish` stages and pushes it with the writer's own files.
- [ ] `DAG.md` is rendered from the snapshot (every chain, stuck roots, cycles, counts, the snapshot's age) plus the month's history, and says which machine token built it and when.
- [ ] `dag_store.load` uses the ledger snapshot when the local file is missing or older (by `built_at`), and says which one it read; with the ledger off nothing changes.
- [ ] Tests: a snapshot is written and filtered (a title handed to it never reaches disk); `DAG.md` matches a golden render; a machine with no local map reads the snapshot; ledger off is byte-identical. Each goes red when its clause is removed.
