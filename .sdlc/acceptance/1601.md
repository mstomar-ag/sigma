## Done when
- [ ] Verify runs in its own process group with a lifeline. Test: start a verify whose command spawns a sleeping grandchild, SIGKILL the caller, assert the group is gone within the grace. Control: revert to `subprocess.run` and see it red.
- [ ] `{workers}` is substituted with an integer only; other braces are untouched. Test: a command and a goal frontmatter value containing `{workers}`, `{other}` and an injection attempt (`{workers}; echo x`) produce an integer substitution and no extra command.
- [ ] Env levers. Test: a real `pytest -n auto` run with xdist installed starts exactly `n` workers via `PYTEST_XDIST_AUTO_NUM_WORKERS`; if the pinned xdist does not honour it the lever is removed in code and the test records that.
- [ ] Hold gives exit 5 with `RESOURCE-HOLD ...` on stderr, no evidence file, and ledger plus action-log events; `record done` still refuses without evidence. Test: fake low-headroom sample.
- [ ] Output memory is bounded. Test: a command printing 200 MB peaks below the stated bound (measured, in the test's docstring).
- [ ] Learned cost. Test: after a run that allocates a known amount in its children, `observed.json` gets peak tree footprint divided by workers within 20 % of the allocation.
- [ ] `mode: off` is unchanged. Test: the existing verify tests stay green and the evidence file has the same shape as before (field-for-field comparison against a golden).
