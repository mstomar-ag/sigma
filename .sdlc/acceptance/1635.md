## Done when
- [ ] AC-1: WHEN a command prints a number as its last stdout line at both commits, THE `quality_delta.py` SHALL print base, head, delta and a `better`, `same` or `worse` verdict honouring the metric's direction.
- [ ] AC-2: IF a command fails or times out at either commit, THEN THE `quality_delta.py` SHALL print `unmeasured` for that metric and SHALL NOT print `same`.
- [ ] AC-3: WHEN a command exceeds its timeout, THE `quality_delta.py` SHALL kill the command's whole process group and remove the scratch worktree.
- [ ] AC-4: WHEN a previous run left a scratch worktree owned by a dead process, THE `quality_delta.py` SHALL reclaim it before measuring.
- [ ] AC-5: IF the merge-base config has no `quality.metrics`, THEN THE `quality_delta.py` SHALL print `no metrics configured` and start no process, even where the head config lists metrics.
- [ ] AC-6: THE `quality_delta.py` SHALL run each command as an argument list without a shell and without `GH_TOKEN` or `GITHUB_TOKEN` in its environment.
- [ ] AC-7: IF the memory probe is unreadable or reads below the derived floor, THEN THE `quality_delta.py` SHALL run no command and SHALL print `unmeasured` for every metric.
