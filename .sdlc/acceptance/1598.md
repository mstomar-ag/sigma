## Done when
- [ ] Limits scale with the machine. Test: for totals of 8, 24 and 128 GiB and 2, 14 and 64 cores, reserve, share cap and CPU reserve scale proportionally (doubling total doubles reserve), and a source scan finds no byte-valued literal of 1 MiB or more used as a limit. Control: add a `4 * GiB` literal and see the scan red.
- [ ] Config handling. Test: `null` or absent gives derived; a valid override is honoured; each of 12 bad values (negative, bool, string, NaN, 0, 1, 1.5, and so on) gives derived plus a note.
- [ ] Hysteresis. Test: a series that dips below the hold line and then hovers between hold and resume stays held and resumes only after `resume_samples` above the resume line; a separate test per clause (lowest-of-three, highest-of-lowest-two, consecutive count). Control: break each clause alone and see its test red.
- [ ] Pressure and critical. Test: level 2 blocks a goal start but admits one verify worker; level 4 and available below half the reserve each give `critical`; PSI absent changes nothing.
- [ ] Swap rate. Test: with the default null the rate never holds; with `swapout_hold_mb_per_s` set it holds and resumes at a quarter of the threshold.
- [ ] `hold.json` is written atomically with `since`, `reason`, `resource`; a truncated or corrupt file reads as open plus a note. Test: kill the writer mid-write (inject) and read back.
- [ ] `docs/configuration.md` lists every `resource` key with default "derived" and the uncalibrated flag. Test: a parity test that the documented keys equal the code's defaults keys.
