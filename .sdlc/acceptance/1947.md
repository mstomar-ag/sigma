## Done when
- [ ] Records are never committed on the default branch: they go to a dedicated records branch with one rolling PR, or through the already-pushed ledger branch and into `main` with the next goal PR (the design picks one and says why in `docs/`).
- [ ] Until that path is available on a repository, the gesture refuses to commit on the default branch and prints the one command that publishes the records.
- [ ] A test runs a recording gesture in a checkout on `main` and shows `main` gains no commit and `git pull --ff-only` still succeeds; it goes red when the commit on the default branch comes back.
