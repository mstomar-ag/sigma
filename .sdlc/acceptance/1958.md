## Done when
- [ ] Every history record carries an `id`: a short hash of the event, its numbers and the source issue's `updated_at` (a record without one, written by an older version, gets the same id computed on read).
- [ ] `dag_history.read_all`, `DAG.md` and the snapshot fold apply each id once; the snapshot records the newest id it includes, and a reader applies only entries after it.
- [ ] Tests: the same change written by two fake writers is counted once; an old record without an id folds to the same id; a real flip (added, removed, added again at a later `updated_at`) keeps all three. Each goes red when its clause is removed.
