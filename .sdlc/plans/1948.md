# Plan: epic-shaped issues without an upper-tier label (goal 1948)

Spec: the issue body (Done when list). Unit: rollout-fixes.

## Behaviour
- New `promote.epic_shaped(title, body)` -> reason string or None. Epic-shaped = title starts with `EPIC`
  (case-insensitive, after optional brackets/space) OR the body has a heading named Slices / Children /
  Child issues / Sub-issues followed by >= 2 issue references (task list or plain list). Pure, no I/O.
- `promote.apply` (arming) refuses an issue with no upper-tier label that is epic-shaped, with a message
  naming the route (add the `epic` label, or reword); the issue is left untouched (no label write). The
  existing `_refusal` stays label-only; the epic-shaped check is a sibling `_epic_refusal(title, body, names)`
  called at the same site. `_read_state` must also give the title without breaking its other callers
  (add the `title` field to the same read, expose it through a new helper or a 5th element handled in all unpackings).
- Migration path (`_migrate_one`) with the same shape: report `would-skip`/skipped "epic-shaped: label it epic",
  never arm.
- `label_drain.verdict` unchanged for labelled tiers; an unlabelled epic-shaped open issue reports
  `upper-tier` with detail "looks like an epic (reason); the picker never takes it" only if title/body are on
  the issue dict it already receives (no extra reads).
- Doctor: one row "epic-shaped issues without an upper-tier label" listing at most 10 numbers plus "and N more"
  from the open-issue data doctor already reads (no new unbounded scan); WARN when any, OK otherwise; silent
  (skipped) when no data. Mirror an existing doctor GitHub-backed row for the offline/unavailable path.
- Config key `epic_label` (default `epic`): DEFERRED (optional bullet); noted PROVISIONAL (owner to ratify) on the issue.

   "epic" mid-title; one issue ref only; heading without refs) -> None.
2. promote apply on an unlabelled epic-shaped issue -> outcome skipped, detail names the route; no label write.
3. Same issue with the `epic` label keeps today's message; an ordinary goal still arms.
4. Doctor row lists the shaped issues bounded to 10 with the count of the rest; OK when none.
Break controls (each clause alone): drop the title clause; drop the body-list clause; drop the >=2-refs
threshold; remove the apply call; remove the doctor row call. Each goes red.

## Risks
False positive refuses a real goal titled "EPIC..." -> the message names the way out (label it or retitle).
Reading the title adds a field to an existing read, no new call.
