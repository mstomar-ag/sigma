# Plan #1609: dag_core, the pure dependency-graph core

Files: new `skills/sigma-loop/scripts/dag_core.py` (standard library only, no I/O, no network or gh import, no file-writing module; sibling modules are loaded the way other scripts load them), new `tests/test_dag_core_1609.py`, registries it touches (script help allowlist for library-only modules, doc/backlog mention only if a test demands), CHANGELOG.md.

API: `Node(number, kind issue|pr, state open|closed|merged|closed-unmerged|unknown, life, prio)`, edges `(blocker, blocked, source)`. `edges_from(text, self_ref)` reuses `blocker_scan.extract_refs` (already unpark-stripped, self and cross-repository skipped after #1608). Functions: `build`, `cycles` (iterative Tarjan/Kosaraju SCC; each distinct cycle once as a sorted tuple; self edge ignored), `closure(goal)` (unresolved transitive blockers; stops at a resolved node), `order` (Kahn, ties by priority rank then number, cycle members excluded), `waves` (level 0 = no open blockers), `open_dependents(n)`, `depth(n)` (memoised), `components`, `leaves`. Resolved = issue closed or PR merged; closed-unmerged PR unresolved; unknown flagged and never resolved. Same input -> byte-identical output (sort everything; shuffle property test). Everything iterative (5,000-deep chain, 50,000-edge fan, no RecursionError).

Measurement (R4): synthetic graphs at 3,000 and 30,000 nodes (chain, fan-in, fan-out, dense random with cycles): time build + closure + components; record the numbers in the PR text (builder reports them to the orchestrator; do not put machine-specific numbers in docs). Loose ceiling test to catch quadratic behaviour (generous bound, deterministic input, not a wall-clock flake: e.g. count operations or use a very loose seconds bound at 30,000).

## Test list
closure/order/waves goldens (chain, diamond, fan-in, fan-out, disconnected, resolved middle); cycles (two, three, two disjoint, tail, self edge, start-independence); deep chain and wide fan; shuffle property; three PR/unknown state tests; ceiling test; structural import test (AST of dag_core imports against a banned list: subprocess, socket, urllib, http, requests, shutil, tempfile, and open-for-write calls). Controls: closed-not-resolved; entry-dependent walk; recursive walk; memo dropped; each seen red.

Risks: determinism across dict ordering; cycle reporting duplicates; recursion; flaky timing test.
