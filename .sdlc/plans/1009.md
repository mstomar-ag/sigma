## Behaviour
- Gate: `decision_rubric.autonomy.applier.enabled` is exactly true AND autonomy and rulebook parts are open. Closed: `tick` returns `[]`, writes nothing, the daemon step spawns nothing.
- An ask is one small file `<state>/autonomy/ask-<id>.json` (`open_ask`, `answer`): issue, qkind, area, options, opened, gesture (`unpark` or `promote`), state. PROVISIONAL: no earlier slice stores asks, so the applier owns this record.
- `window_open(ask, config, now)`: now is before opened plus `window_minutes`.
- `tick(sdlc_dir, config, now, source=None, run=None, apply_actions=True)`: for each pending ask, skip if a person answered, if the window is open, if the kind is hard-stop, if `autonomy.level` is below 3, or if there is no single approved sealed rule match (`rulebook.match`). Stop at `max_auto_applied_per_day` (rolling 24h, counted from applied asks plus this tick). Applied asks that a person answered "no" to after the window yield a `veto` action, which calls `autonomy.veto` (drops a level, may pause).
- Level 3 acts and tells (comment names the rule id). Level 4 is silent only when `silent_allowed(qkind, config, rule)`: kind listed in `allow_silent`, not hard-stop, and the rule is an approved sealed rule (approval already required `is_owner`). Every `spot_check_one_in`-th ask (stable hash of its id) still tells.
- `apply(action, ...)`: unpark = one `swap-label` through `triage.apply_actions` (same shape as the sweep, plus card move); promote = `promote.promote`. Then comment, an autonomous decision record, and the ask state, written atomically.
- `tick_is_dead(heartbeat, config, now)`: heartbeat missing or older than `stale_after_intervals` watch intervals. Heartbeat file written at the end of every open-gate tick.
- Defaults (PROVISIONAL, most conservative): `allow_silent` [], `window_minutes` 1440, `spot_check_one_in` 5, `max_auto_applied_per_day` 3, `stale_after_intervals` 3.
