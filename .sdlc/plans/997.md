# Plan 997: class-bound recorded permission and marker scrub (decision rubric slice 7)

## Goal
Bind the recorded spend permission to a class, an optional action digest and a durable use counter, and add a marker scrub helper. Gate closed (no class, no digest, counter absent) keeps today's output.

## Steps
1. `spend_approval.py`: `check(..., hardstop_class=None)`. A class that is not exactly spend, or not in `spend_approval.classes` (default spend), is DENIED with a reason; the check runs after the OFF test and before any read.
2. Optional marker suffix `:<12 hex>` is the first 12 hex of sha256 of the whitespace-normalised action; mismatch is DENIED. `parse_marker` keeps its 3-tuple.
3. Counter file `.sdlc/state/spend-approval-used.json`, read before grant, written (atomic replace) after the audit comment posts and before APPROVED; a write failure is DENIED.
4. `scrub_marker(body) -> (body, changed)`: first line carrying the marker becomes a code span.
5. `run_verb` accepts `--class <name>`; usage string, template key `classes` and note, docs lines, CHANGELOG.

## Test list
Six tests: non-spend class refused, no class unchanged, hash mismatch, counter survives comment removal, marker scrub, documented gesture refuses another class; plus the exact-dict pin update.

## Controls
Remove the class check and see the first test red; break the counter read and see the counter test red.

See the acceptance file for the goal.
