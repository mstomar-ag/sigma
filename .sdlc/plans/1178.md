# Plan 1178: open and close asks at park and answer

## Files
skills/sigma-loop/scripts/applier.py (two new functions), loop.py (record parked), handoff.py (_triage_finish park), unpark.py (_comment_decision), promote.py (promote verb), tests/test_applier_wiring.py (new). No SKILL.md edits (context-budget ratchet).

## Behaviour
- `open_for_park(sdlc_dir, config, issue, qkind_, source=None, now=None)`: returns an ask id or None, never raises. Closed gate (`applier.enabled` false) returns None before any read. Needs a valid declared kind that is not a hard-stop kind; area from the issue labels read best-effort through `source._read_issue` (fallback `repo`); `rulebook.match(qkind, area, None, rules, config)`; no match opens nothing; a pending ask for the same issue is reused (idempotent). The ask options are the matching rule's option, the pre-fill is that match. PROVISIONAL (owner to ratify): "learned pattern" is served by the same approved-rule match the tick uses.
- `close_for_issue(sdlc_dir, config, issue, text, now=None)`: answers every pending ask of the issue with the person's text (existing `answer`, so the person wins and the tick skips it). Never raises. Skipped while the applier itself is applying (module flag), so its own promote gesture does not close its ask.
- Callers: loop.py record parked with a declared kind, and handoff park-at-filing, call open_for_park after the park lands; unpark.py `_comment_decision` (covers unpark and keep-parked) and the promote verb call close_for_issue. Each call in try/except: a failure never blocks the gesture.

## Test list
- open: matching approved rule opens one ask with option and area; no rule opens none; hard-stop kind opens none; second park reuses; gate closed opens none and makes zero source calls.
- close: unpark and keep-parked via the real verb with a stub source close the ask as answered; promote closes; applier-driven promote does not.
- Real path: real record-parked chokepoint, then tick past the window applies via swap and comments rule id; person answer inside window wins; a "no" after apply is a veto; level 3 and level 4 both applied.
- Wiring removed (call patched out) -> nothing applied (red control).
- Gates closed: output of record parked / unpark byte-identical to before (compare to a source recording).
- Failure of open/close (raising module) never blocks the gesture.

## Scale
One small file per open ask, one listing per tick and one per close (O(asks)); at 10x/100x open asks tick cost is linear in files, bounded apply by the daily cap, pruning exists (applier _prune). open_for_park scans asks once for the reuse check.
