# Plan: the stamp and the resolution record (part B, slice 4)

## Goal
When the engine resolves a unit conflict it can stamp the replayed commit, commit it at the stop with the original
author kept, and record the resolution in three places. Nothing calls this yet; the callers (slice 5) sit behind the gate.

## Files
- `skills/sigma-loop/scripts/feature_upkeep_resolution.py` (new library, no CLI): the stamp builder and wording check, the stamping commit, the authorship comparison, the record store, the ledger note, the comment poster.
- `tests/test_upkeep_resolution.py` (new): all controls below, real git where git is the claim.
- `tests/test_legacy_compat.py`: the stamp key joins `_NOT_MARKERS` (a new lowercase key, no retired spelling).
- `tests/test_script_help.py`, `tests/test_feature_registry.py`: library list, fold inventory entries.
- `tools/readiness/write_surface.py`, `docs/launch/write-surface.json`: rows for the prune and the comment post.
- `docs/launch/dispositions/945.json`: growth dispositions for the resolutions store.
- `CHANGELOG.md`: one entry on its own line.

## Behaviour
- Stamp: `sigma-resolution: <level> <run id>`, level 1 or 2, run id 12 lowercase hex. `stamp_message` appends it after a blank line, or into a trailing trailer block; the subject is never touched.
- Wording check over stamp, record and comment text: no `#` followed by a digit, no closing-keyword shape, no issue or pull URL path, no registered marker substring (either spelling).
- Stamping commit: `git commit --no-verify --no-gpg-sign --author=<original> --date=<original raw> -m <message>`. Author name, email and timestamp come from `REBASE_HEAD`; the committer is the engine, which is true. D-42 choice (PROVISIONAL): the author-flags form, which needs no newer git than the engine already runs; the amend-with-trailer form is not shipped.
- Hooks and signing (MEASURED with real git 2.49, see the test docstring): `rebase --continue` on a staged resolution runs only the prepare-commit-msg and post-commit hooks and never asks the signer; a plain commit at the stop runs all four hooks and asks the signer. The engine commit passes `--no-verify` and `--no-gpg-sign`, so it runs the same two hooks as the continuation and no signer: it adds nothing the replay would not have done, and a hook or key prompt cannot stall it.
- Record: one JSON document per resolution in the resolutions directory under the upkeep state directory, named unit key, a dash and the run id, atomic, symlink-refusing, capped size on read; `prune` removes records older than a given number of days (caller passes it).
- Ledger: one unaddressed `note` keyed by the unit key with a `resolved` ref, written in process with `ledger.safe_append`; never addressed, so autowatch and the webhook stay out.
- Comment: through `gh_api.comment_issue` with an integer id and an explicit repository, only when the caller names a finding; with none, nothing person-facing is created (D-21: local plus ledger always). D-4 GitHub half stays unverifiable offline; the stamp and record carry no number, so the question does not arise for them.

## Check list
- Stamp shape: blank line built, trailer block reuse, subject untouched, git parses it as a trailer.
- Red control: stamp appended with no blank line joins the subject and the arrival classifier reads DIRECT.
- Wording: closing keywords, numbers, URLs, marker substrings (both spellings) refused; the leak scan passes the stamp.
- Registration: the marker-literal pin sees the key and the pin list holds it.
- Stamping commit at a real stop: author name, email and timestamp equal the original; `rebase --continue` keeps the sha.
- Red control: a plain commit at the stop fails the authorship comparison.
- Hooks and signing measurement with a failing signer and recording hooks.
- Record store: atomic write, symlink refusal, bad unit, read back, prune by age only, unreadable files left alone.
- Ledger note: unaddressed, keyed, ref present; ledger off writes nothing.
- Comment poster: integer id and repository required, wording refused, no finding means no call.
- Closed gate: no shipped module imports the new library (byte-identical paths).
- Pins: library list, fold inventory, write-surface, disposition.

## Risks
- The stamping commit at a merge stop is not covered (a merge stop parks in a later slice).
- Measured on one git version (2.49) and one machine; older gits are unmeasured. The pre-commit and commit-msg hooks never run at a stop either way.
- Comment posting is not idempotent (gh_api says so); the caller posts once, just before closing.
