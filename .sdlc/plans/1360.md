# Plan 1360: stop re-reading comments for stuck pending asks

## Behaviour
In `applier.read_vetoes` a pending, unanswered ask whose age since max(opened, armed_at) exceeds 2 x window_minutes is "stuck": it is read for owner comments only when `veto_read_at` is absent or older than one window; after a read the tick writes `veto_read_at` onto the ask file (atomic write, like `answer`). Younger pending asks and applied asks behave exactly as before. Unparseable times read as young (safe: read).
