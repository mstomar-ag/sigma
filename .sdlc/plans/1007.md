## Behaviour
- Config: `decision_rubric.rulebook.enabled` (exact true), `.path` (default `.sdlc/rulebook.json`, relative to the repository root, parent escape or absolute refused), `.reask_days` (default 90). Wrong type reads as default.
- Rule: closed key set `id, qkind, area, option, reason, status, created, confirmed, seal`. No person field exists; any other key makes the rule invalid. qkind must be in the closed qkind list.
- `propose(sdlc_dir, draft, config)` writes the rule as `proposed` into the rulebook file (atomic replace), returns the path; `park_line(rule_id)` is the single park text carrying the owner_hold kind line. Imported rules use `import_rules`, which calls propose for each, so every rule starts proposed.
- `approve(sdlc_dir, rule_id, login, config)` refused unless `autonomy.is_owner`; sets status approved, confirmed time and a seal (hash of the content; tamper evidence, not authentication). The approver is not stored.
- Only a rule that is approved AND whose seal matches acts as approved; a hand-edited approved rule without a valid seal is treated as proposed.
- `match(qkind, area, option, rules)`: recommend only; hard-stop kinds never match; zero or several matches return None (ask).
- `due_for_reask(rules, now, config)`: approved rules whose confirmed time is older than reask_days.
- Closed gate: all entry points return empty and write nothing.
