# Plan 1330: unit pass only when the engine did not look

## Behaviour
`feature_upkeep_job.run_engine` runs `_unit_pass` for every outcome that is not rebased or a FAILURE word. That includes the neutral words disabled, busy, remote-unreadable, no-base, no-unit and not-adopted, so a unit is force-pushed lease-only with no backup although the engine refused. Change: the unit pass runs only for an allow-list (`current`, `no-branch`); every other outcome reports `unit_pass: skipped`. PROVISIONAL (owner to ratify): the smaller design (skip) is taken rather than routing the pass push through the backup guard.
