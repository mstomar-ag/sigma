## Behaviour
Reads `spend` and `phase` events from `<sdlc>/events/*.jsonl` (fields `kind`, `goal`, `phase`, `cost_cents`, `ts`). Torn lines skipped.
- `estimate(sdlc, members)`: per-goal totals of `cost_cents` for NON-member goals with spend events (earlier completed goals); fewer than 3 returns `(None, "no estimate: only <n> measured goals")`; else dict p50, p90 (nearest rank, cents), basis.
- `spent(sdlc, members, since)`: sum over spend events whose goal is a member and `ts >= since` (epoch or ISO). Goal number match only.
- `admit(sdlc, config, chain, now)`: caps `chain.max_usd`, `chain.max_goals` (default len(members)+`chain.max_added`, default 5), `chain.max_minutes` (default unset). No cap set: ok, disk untouched. Unreadable ledger with a cap set: refuses. spent + unpriced-phase projection (member phase events with no spend event, each at per-phase p90; no p90 with a cap set refuses) >= max_usd refuses. Returns `(True, "")` or `(False, "capped: <reason>")`.
- `OVERSHOOT_SENTENCE`: the cap is checked before each claim, so it can be overshot by the cost of the goals in flight.
