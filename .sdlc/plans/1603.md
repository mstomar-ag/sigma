# Plan 1603: admission before Sigma-spawned model sessions

Goal: `resource_guard.session_lease(kind, goal)` context manager used by the three spawn sites.

## Files
- `skills/sigma-loop/scripts/resource_guard.py` (helper; lazy-imports resource_lease inside the function to avoid the import cycle), `feature_judge.py` (ask_claude), `supervise_daemon.py` (the Claude launch and Codex capture), `feature_upkeep_launcher.py` (launch), new `tests/test_session_lease_gate.py`, `docs/launch/write-surface.json` if a new write is registered, CHANGELOG Unreleased.

## Behaviour
- `session_lease(kind, goal, repo=None, ttl=None, env=None, config=None)` yields a Lease or a Hold. mode off (resolved from config, default per resource_guard) yields no lease and writes nothing. Otherwise it calls resource_lease.admit(kind "session") and releases in `finally` (also on exception or timeout).
- Judge: on Hold, `ask_claude` returns `(None, 0.0)` and appends the hold reason to `reason_out` (existing refusal path).
- Supervisor: on Hold the launch is skipped as a crash-backoff pause and relaunched (same path as an existing backoff).
- Upkeep launcher: on Hold returns the existing deferred Result with the reason.
- Never raises: Unsupported platform or a lock error maps to "no lease, proceed" is NOT allowed when mode is enforce on a supported platform; on Unsupported treat as the existing "could not run" outcome only if the module already refuses elsewhere, else proceed unguarded (document in code).
- Ratchet test: scan scripts for source files containing the host CLI spawn (claude -p / codex exec argv builders) and require each in a GATED list; control: temp file with an ungated spawn fails.
- Grep-level test: the three sites call `session_lease` and none calls `resource_lease.admit` directly.

## Test list
Lease present while a stub child runs, gone after, after exception and after timeout (each site); hold mapping per site; mode off creates no lease dir; ratchet with red control; one CLI-path scenario via the existing entry of the upkeep launcher with a fake child.

## Risks
Do not break existing tests of the three modules: tests must set SIGMA_RESOURCE_DIR to a temp dir or mode off by default; new spawns must keep old behaviour when gate closed.
