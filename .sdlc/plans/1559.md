# Plan #1559: upkeep preview (sweep-level dry run)
## Behaviour
`feature_rebase.py preview <sdlc_dir> [--fetch]` lists every unit the sweep would consider (registry units, `upkeep.units.include/exclude` applied via feature_upkeep_sched.selected) with a predicted outcome: current (base is ancestor of feature), fast-forward (feature is ancestor of base... or no feature commits), clean rebase, conflict (+ file list), refused (+ reason: no base, no remote branch, direct commits not acked, upkeep gate closed is NOT a refusal: preview works with the gate closed, that is its purpose). Prints JSON (units list, each: unit, branch, outcome, why, files). Moves no ref, no push, no worktree, writes nothing outside .sdlc/state (default: writes nothing). No fetch by default (reads the remote-tracking refs, says "as of last fetch"); `--fetch` runs a plain fetch (remote-tracking refs only). Conflict prediction: `git merge-tree --write-tree --name-only` of base vs feature (writes content-addressed objects only, no ref); a rebase may conflict where the merge does not: documented as a prediction.
## Files
skills/sigma-loop/scripts/feature_rebase.py (new `preview` fn + main branch + USAGE), docs/upkeep.md (use it in "Turning it on" before `show`), CHANGELOG.md (line under Unreleased end), docs/launch/write-surface.json only if a new write/delete-shaped call is added (none intended), tests/test_script_help.py if it enumerates verbs.

New tests/test_feature_rebase_preview.py on a throwaway `git init -b main` repo with a bare remote: units current, fast-forward, clean rebase, conflict (file named), refused (direct commit or missing remote branch); assert refs unchanged (git for-each-ref before/after), no files outside .sdlc/state; CLI invocation of the documented gesture; gate closed still previews.
