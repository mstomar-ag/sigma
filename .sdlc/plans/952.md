# Plan 952: B11 doctor rows and readiness for resolution

Goal: when the upkeep block is open AND `conflicts.resolve` is `agent`, the doctor adds resolver/reviewer readiness
rows and a liveness-by-age row. In every other case it adds NOTHING (byte-identical output).

## Design
- New `_resolver_rows(base, cfg, which, cheap_only, now)` in `skills/sigma-doctor/scripts/doctor.py`, called right after
  `_upkeep_rows`. It reads settings only through the gate module (`feature_upkeep.read`), never the raw block.
- Silent unless reading.enabled and settings `conflicts.resolve` == `agent` (invalid block: the scheduler rows already
  say so; this adds nothing).
- Rows: resolver CLI present (`which`, cheap); confirmed-flag table state (launcher UNVERIFIED_FLAGS non-empty = not
  ready); model id not the placeholder (launcher CATALOG); finite spend cap (no cap key in the gate schema yet = not
  ready, self-updates when a cap key is added; non-finite value = not ready); reviewer store (state dir shape).
- Bounded probe: the CLI `--version` through `_bounded_run` with a short timeout, skipped under `cheap_only`. The flag
  `--version` for the resolver CLI is UNVERIFIED against a real binary. No model is ever run.
- Liveness by age: resolution records under the store: oldest record age vs `backup.keep_days` (PROVISIONAL: older than
  the prune horizon means the prune never ran). Parked-finding age: no store exists yet, UNVERIFIED, not read.
- The existing unbounded `claude plugin list` calls are NOT touched (D-25); reported as a follow-up.
- Reference file `skills/sigma-doctor/references/resolver-readiness.md`; linked from SKILL.md.

## Test list
- gate closed (block absent, disabled, resolve off/mechanical, invalid): `check()` rows identical to a baseline config
  without the block; no `_bounded_run` call.
- open + agent: the five readiness rows exist; placeholder model row fails; cap row fails; flags row fails.
- bounded probe: cheap_only never calls `_bounded_run`; otherwise it is called with a timeout and a hung/failing CLI
  yields a failing row, no exception.
- liveness: a record older than keep_days fails the age row; a fresh one passes; none = no age row failure.
- reference file exists and every backticked path in it resolves; no bracket-paren sequences.
- test_script_help and the enforcement/inventory pins still pass.
