# Plan: per-category autonomy thresholds (goal 1221)

## Approach
- New library `skills/sigma-loop/scripts/categories.py`: reads the optional file `.sdlc/categories.json`
  (schema `sigma/categories@1`) from the state directory. Never raises. A wrong schema, unreadable file
  or non-list `categories` reads as no categories. An entry with a missing or duplicate id, an unknown
  threshold key, a wrong-typed value, bad `areas` or bad `qkinds` is dropped on its own; the first of
  two entries with the same id wins. `resolve(sdlc_dir, qkind, area)` returns the first category whose
  `areas` contain the area (and whose `qkinds`, when given, contain the kind).
- `autonomy._state` applies the category `levels` over `settings(config)` key by key, and adds the
  keys `category` and `thresholds` to its row only when the file exists. Gate closed or file absent:
  the row and the doctor line are byte-identical to today.
- The doctor autonomy clause appends the category id and the thresholds in force when the row carries them.
- Docs: a section in `docs/configuration.md`. The template ships no categories file.

## Files

## Test list
- reader fail-safe cases (missing, bad JSON, wrong schema, duplicate id, unknown key, wrong type)

- two pairs, one overridden, other unchanged
- readout and doctor show category and thresholds; absent file gives identical rows and text
- closed gate gives the closed readout
- schema string and precedence pinned; docs mention the file; template has no categories file
