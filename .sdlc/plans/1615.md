# Plan 1615: DAG cycles reported and held (R5)

Spec: the issue body (Done when, 7 bullets), epic design "Cycles", owner decision 7 (one comment per distinct cycle even in shadow mode, switchable). Map facts: the stored map (`dag_store`), cycles from `dag_core.cycles` (strongly connected groups of 2+ unresolved nodes), refresh in `dag_refresh.refresh_if_due`, switches `dag_store.mode` and `dag_store.cycle_comment` (already exist, default true).

## Files
- NEW `skills/sigma-loop/scripts/dag_cycles.py`: `find(sdlc, config)` -> list of sorted member tuples from the STORED map (no network; [] when mode off, map missing or unusable); `line(cycle)` the one-line text (numbers only); `lines(sdlc, config)`; `comment_body(cycle)` (marker `<!-- sigma:dag-cycle 3,7,9 -->` plus a fixed instruction to remove one `Blocked by` line; numbers only, no titles/names); `post(sdlc, config, run)` posts ONE comment per distinct cycle on the lowest-numbered OPEN member, after reading that member's comments for the marker (a second refresh posts nothing; a changed member set has a new key so posts one new comment); silent when mode is `off` or `cycle_comment` is false; bounded (at most 20 cycles per call); never raises; writes only comments, never labels or claims.
- `skills/sigma-loop/scripts/dag_refresh.py`: after a `saved` refresh call `dag_cycles.post` through the same bounded runner, guarded so it can never fail the refresh.
- `skills/sigma-loop/scripts/loop.py`: where the DONE path prints "nothing pickable — N goal(s) are waiting on an open prerequisite", if any held goal is a member of a stored-map cycle, do not say "They become pickable by themselves"; say those goals never release by themselves and print one `loop.py: dependency cycle ...` line per distinct cycle naming every member. Mode `off` or no map: bytes unchanged.
- `skills/sigma-status/scripts/status.py`: a ` | dependency cycle: #A, #B -> remove one Blocked by line` segment per cycle (silent with none, with mode off, with no map).
- `skills/sigma-doctor/scripts/doctor.py`: a row `dag cycles: ...` naming every member of every distinct cycle, not-OK with the one fix (remove one `Blocked by` line); absent when none or mode off.
- docs: where `cycle_comment` / the map is documented, one sentence on the cycle report and the comment (find with grep over docs and skill cards); CHANGELOG `## Unreleased` entry; `tests/test_script_help.py`/write-surface inventory/registries updated if the new module trips them (new `comment_issue` call site goes through `gh_api`, never raw `gh`).

## Behaviour contract
- A hand-made cycle is held exactly as today: no picker change, members unclaimed, nothing written to them except the one comment.
- An independent goal is still picked while a cycle exists elsewhere.
- Mode `off`: every output byte-identical to before (test), no `dag_cycles` import on the pick path.

## Risks
- Comment spam: bounded by the marker read and the 20-cycle cap; the read costs one call per cycle per refresh (state the number in the module docstring).
- A cycle whose lowest member is closed: use the lowest OPEN member; none open -> no comment.
