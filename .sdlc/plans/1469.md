# Plan 1469: migrate-confirmation keeps the board-card result

## Goal
`promote.py migrate-confirmation --apply` must not report `complete` while an armed card did not reach
the Ready lane on a board-queue repo, and a migrated park must move its card to Parked (fallback Blocked).

## Files
- skills/sigma-loop/scripts/promote.py: `_migrate_one`, `migrate`, `render_migrate`.
- tests/test_promote_migrate_board.py (new).
- CHANGELOG.md: one line under Unreleased.

## Steps
1. Arm: keep the bool from `_set_board_status(n, col["ready"])`. If False and the source has an active board,
   add a note naming the column and set `card_unmoved`. The dead except stays as a safety net (a raise is also unmoved).
2. Park: when the board is active, move to Parked, fall back to Blocked (`warn=False` on the first try);
   note when neither lands. No board: no new call (byte-identical).
3. `migrate()` counts `cards_unmoved`; when the source's `_ready_lane()` is set and the count is above zero,
   `complete=False` (exit 1).
4. `render_migrate` prints a summary line naming the unmoved cards and the fix, only when the count is nonzero.

## Test list
- arm with a False board write: note, `card_unmoved`, count, summary line, exit 1 via the CLI path.
- park with False on both lanes: note, count of park notes, no incompleteness from a park alone.
- park lands in Parked; Parked refused falls back to Blocked.
- no board active: no park board write, no note, output identical to a board-less run, exit 0.
- board active but no Ready lane (label queue): note yes, still complete.
