## Behaviour
- Answers file = JSON object mapping question ids (from `plan` questions) to an option from that question's options (free text only where the bank allows). Validate the whole file first: unknown id or option outside the bank -> message on stderr, exit 2, zero writes.
- Per answer: label write first, then `decision_record.build` + `write_all` (record: qkind, area, choice, scope `label:<name>`; member-level area = member area label, label-level = `repo`). Failed label write -> no record.
- Effects: label_set arm route -> reuse `arm(apply=True)` restricted to the chosen subset; parked-member route -> reuse the existing `unpark.py resolve` path, never reimplement; dependency (pulled blocker) -> label+arm or leave; irreversible `go ahead` -> write first-line marker `sigma:spend-approved=<token>` (token from label: letters digits . - _ max 64) on approver-authored paid members only (reuse spend_approval helpers/approver set), name non-approver members in output; `do not`/`change the plan` -> record only.
- Omitted question stays open; after applying, re-run `plan` and print open questions and `ready`.
- Idempotent: second identical answer -> one record, one effect (decision_record repeat handling). Crash recovery: effect already applied by state -> leave effect, write missing record.
- --dry-run prints every would-be write, makes none.
