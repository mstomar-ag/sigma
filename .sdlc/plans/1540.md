## Fixed behaviour (decisions 1-10, implemented as written)
Output per path: `<path>\t<zone>\t<state>\t<rule>`; zone in legacy|modern|undeclared|unreachable; state in new|existing|unknown. Path echoed normalised (strip `./`, `\` to `/`, absolute-in-repo made relative; outside repo or `..` escape = typed refusal, exit 2).
Rules: legacy+existing `legacy: change only what the goal needs; extend by sprout or wrap at one seam`; modern (any state) or any new path `follow sound design: structure for the forces the goal names`; undeclared+existing `follow the surrounding code`; state unknown `unknown: merge-base unresolved; apply no zone rule`; zone unreachable `unreachable: config unreadable; apply no zone rule`.
Precedence: unknown/unreachable rows first (never print a zone rule), then new (new-code rule, zone still printed), then per-zone rule.
Glob: `fnmatch.fnmatchcase` on the normalised path, last match wins. Config: `.sdlc` via git-common-dir (reuse north_star.project_root by path load, not a re-implementation, closing dossier D-2). Missing/unreadable/non-object config or unresolved root = `unreachable`; config without `design`/`design.zones` = `undeclared`; malformed zones = refusal naming the entry index (`design.zones[i]`), exit 2, empty stdout.
Fork point: base_ref = `<remote>/<base>` from the worktree record. The record is found by scanning `<common .sdlc>/state/work/*.json` (plain JSON, not importing work.py) for the one whose `branch` equals HEAD's branch (`git symbolic-ref --short HEAD`); the branch prefix is NOT assumed (work.py `branch_prefix` is configurable). No `--goal` flag. `--base REF` overrides. `git merge-base HEAD <ref>` gives the fork. Newness is ONE batched call: `git cat-file --batch-check` fed `<fork>:<path>` lines on stdin; a `missing` line = new, an `<oid> <type> <size>` line = existing, any non-zero rc, timeout, or unparseable/short output = unknown for every path (real behaviour: `cat-file -e` returns 128, not 1, for a missing path, so it is NOT used). No record, no ref, failed merge-base, detached/unborn HEAD, shallow failure = unknown for every path. A directory argument is classified by the string only and reports existing when the tree entry exists, even if files under it are new (documented).
Path base: relativise to `git rev-parse --show-toplevel` of the CURRENT worktree; the common root from north_star.project_root is used only to find `.sdlc/config.json`. Relative args are joined to cwd first; both sides are `os.path.realpath`ed (macOS `/tmp` is `/private/tmp`); a result that escapes the toplevel after resolution is refused, one that resolves back inside is accepted.
CLI: argparse, `classify` subcommand, `--help` has "usage", tail uses `timing_store.timed_main` exactly as north_star.py:208-217.
