## Behaviour
- Gate: part `autonomy` open in decision_rubric_cfg. Closed: level 0, record_watch/veto/prune write nothing, readout says disabled.
- State lives in `<sdlc>/autonomy/` as one file per fact (`watch-<id>.json`, `veto-<id>.json`), created exclusively; keyed on kind and area plus a hashed machine tag; no login anywhere.
- Level: answers = records with how human for the exact kind and area (decision_store). Level n needs answers >= l_n_min_answers and, for 2 to 4, a machine's watch comparisons >= that minimum with agreement >= l_n_agreement. Each machine gets a level; the result is the minimum over machines (no watch data: capped at 1).
- Veto: one level off when any veto exists; paused (0) at veto_pause_consecutive vetoes since the last agreeing watch record, or veto_pause_total in all.
- Hard-stop kind (hard_stop.is_hardstop_kind, or any record carrying a hardstop_class): capped at 2, fixed.
- prune_watch drops watch files whose embedded time is older than watch.retention_days; vetoes are kept; links skipped; never raises. record_watch runs it behind a daily stamp.
- is_owner: autonomy.owners, else spend_approval.approvers; empty or malformed refuses.
