# Plan 1307: imported decisions agree on a normalised shape

PROVISIONAL: the shape fields and their buckets are the smallest design that makes agreement
reachable on the data seen (282 of 293 choice texts unique, replay agreement 0 of 129). The bucket
choice (see Behaviour) is a guess to be re-measured on a real import; revisit before relying on it
to draft rules. Nothing here changes level thresholds or the hard-stop path.

## Files
- edit `skills/sigma-loop/scripts/decision_import.py`: new `shape_of`, `replay` compares a row's `shape`
  when it has one, `_evidence` fills `shape` (from the candidate, or from a stored record), `plan`
  and `apply` compare/record the same key; imported records gain an optional `shape` string.
- create `tests/test_decision_agreement_shape.py`
- edit `CHANGELOG.md` (one line under Unreleased)
- No edit to `autonomy.py`: it already compares `would` with `actual`; apply passes shapes as both.

## Behaviour
- `shape_of(cand)` returns a short enumerated string `<rk>|<rec>|<role>` or None:
  rk = `resume` / `keep` / `-` from the choice words; rec = `rec` when the chosen option carries a
  "(recommended)" marker, `norec` when options exist without it, `?` with no options;
  role = `first` / `later` / `free` (chosen text not among options) / `?` with no options.
  None when the candidate has no options and no resume/keep word (nothing normalised to compare).
- `replay` keys a row by `shape` when present, else by exact `choice` (old behaviour, unchanged for
  rows with no shape). Majority-of-earlier rule and tie rule are unchanged.
- `plan` agreement and `apply` watch files use the same key: `would` and `actual` are shapes for
  shaped rows, texts otherwise. Shapes are enumerations, so they survive public visibility.
- Records carry no login or person field; the new `shape` field is enumerated text only.
- Closed gate: `apply` returns before any of this; `plan` of rows with no options is unchanged.

## Test list
- same shape, different labels: replay agrees and a pair reaches level 2 through plan
- control: exact comparison of the same rows gives zero agreement (the pre-fix result)
- rows with no shape fall back to exact choice comparison
- different shapes do not agree
- closed records gate: apply output and files byte-identical to the empty result
- rubric parts: rulebook gate closed still writes no rule; autonomy closed writes no watch
- records hold no person fields; `shape` is stored on the imported record
- documented gesture: `apply` then second `apply` writes nothing more

## Risks
- Over-merging: unlike options may share a shape and agree falsely. Mitigated by keeping
  level thresholds and the cap on imported levels (`IMPORTED_LEVEL_CAP`) unchanged.
- Two other builders edit `decision_import.py` (`_from_comment`, classify/apply timeout): the diff
  here stays inside `replay`, `_evidence`, `plan`, `apply` record/watch lines and one new helper.
- Old stored records have no shape: they fall back to exact text, so old and new rows never agree.
