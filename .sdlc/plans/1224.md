# Plan 1224: session-start report of units upkeep will rebase

## Goal
At session start, report (never act on) registered units that the upkeep scheduler would take next. Accelerator only; the loop pick and the scheduler stay the mechanism.

## Design
- `feature_upkeep_sched.due_units(config, sdlc_dir, now, budget, clock, deps)`: read-only twin of the decision half of `scheduler_tick`. Project door only (a session shell has no machine variable). Same include/exclude, cooldown filter (state read only), measure and `decide` rule, same per-call time budget (a quarter of the call timeout). Writes nothing, not even the status file. A unit whose count is not an int goes to `unknown` and is never due.
- `skills/sigma-loop/scripts/upkeep_session.py lines <sdlc_dir>`: new Python entry point (host-agnostic, directly callable). Prints at most 3 lines `unit X is N merges behind main; upkeep will rebase it` then a count line; nothing when the gate is closed, nothing is due, or anything fails. Always exit 0.
- `hooks/session_start.sh`: only runs that script and joins its output into the existing notice slot, so there is still exactly one additionalContext. Skipped under `SIGMA_RUN_ID`. No output means the hook is byte-identical.
- Registered in the sigma-loop skill card inventory (guard tests require every script there). No SKILL.md text change.

## Ceilings
Per unit cost is one measure (bounded git reads); the time budget caps the whole call at 30 s by default, units not reached are simply not reported (the scheduler still handles them). At 100x units the report covers the units measured inside the budget.

## Test list
1. due: unit behind with no success is returned with arrivals, age and reason.
2. not due: behind 0 and within backstop are not returned.
3. cooldown: a unit inside its cooldown is not measured or reported.
4. gate closed: empty result, nothing measured, no state written.
5. unmeasurable: listed as unknown, not due.
6. writes nothing: sdlc tree identical before and after.
7. entry point: max 3 lines then count; closed gate and failures print nothing, exit 0; hook-less direct call.
8. hook: gate closed and nothing due output byte-identical to the hook without the tier; due lines appear in the one JSON blob.
