# Plan 934: cross-repo unit check (part C, slice 7)

## Goal
Before the landing engine merges a unit onto main it can ask one question keyed by the unit: has every other
repository's half landed. Refuse when one has not, and when the lookup cannot answer.

## Files
- `skills/sigma-loop/scripts/cross_repo.py`: `unit_sibling_check` and a bounded read-only scan of the landing records.
- `skills/sigma-loop/scripts/work.py`: `unit_sibling_guard` (thin, gated, total) and its enforcement row.
- `docs/enforcement.md`: regenerated.
- `tests/test_unit_sibling_guard.py`: new.
- `CHANGELOG.md`: one entry.

## Behaviour
- Siblings are the repositories other than this one named by the unit's landing records (tier 1 or tier 2) or the
  feature registry entry. Repo names compare case-insensitively.
- The caller supplies `landed(repo, branch)`; only the boolean True passes. False, None, other values, an exception or
  no callable all refuse, naming the sibling.
- Fail closed on error, not absence: an unreadable or symlinked record, a record this release does not understand,
  a flagged or unknown decision, an unreadable registry, a sibling with no recorded branch, or more records than the
  ceiling all refuse. No records and no other repository passes with no lookup.
- Gate closed: the guard returns pass without reading anything. Never raises.
- Seeds: the goal-keyed store is only read (its path rule and schema reused, store untouched); the goal-keyed
  `sibling_gate` stays unwired and exempt, and the exempt set does not change.

## Check list
- sibling landed passes; not landed refuses and names it
- lookup cannot answer (raises, None, non-boolean, no callable) refuses
- corrupt, foreign-schema, symlinked record refuses; flagged record refuses; tier 2 still checked
- no records, single-repo unit, other units records: pass with zero lookups
- sibling without branch refuses; repo spelling case-insensitive
- ceiling refuses; lookup writes nothing
- hostile inputs never raise; gate closed (several non-true spellings) changes nothing
- registration present, exempt set unchanged, guard does not call the goal-keyed check
- controls: pass-on-None, drop flagged refusal, drop gate check, skip unreadable record; each must go red

## Risks
- The ceiling of 5000 records is PROVISIONAL and unmeasured; cost is linear in records ever written, nothing prunes them.
- Tier 2 is treated as a pair (refuse), unlike the goal-keyed check; PROVISIONAL, matches the refusal decision.
- Nothing calls the guard yet; the engine slices wire it and supply the landed measurement.
