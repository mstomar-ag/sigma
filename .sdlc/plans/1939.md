## Behaviour
- Wait time always from the refused response (headers or Retry-After). With only gh's stderr (no headers, which `gh api` hides without `-i`), the documented gesture is `gh api -i`; absent headers the bounded defaults apply. `/rate_limit` is never the source of a wait time.
- Secondary limit is distinct from primary everywhere it is named (doctor row, remedy, bucket `kind`).
- A pick and `label_drain plan` need no GraphQL for the label check.
