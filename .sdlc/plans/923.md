# Plan: #923 the upkeep scheduler and health rows (design slice 7)

## Goal
A gated machine-level decision step in the watch tick picks at most one due unit and starts a detached bounded job; the
watcher records outcomes as unaddressed ledger notes; the doctor shows liveness and readiness rows including the git floor.
Gate closed: byte-identical.

## Decisions (each checked against the tree)
- Decision step lives in a NEW module, feature_upkeep_sched (gated machine door, registered). The watcher loads it lazily
  through a cached loader, after the eight calls, in its own guard (a failure logs the class name only). No heartbeat touch.
- Config is re-read each tick (fails open to empty, which reads closed). The machine variable stays the one fixed at start.
- Nothing but the gate reads the block: settings come from the gate reader; the engine is called as a function, no argv.
- Per tick: reap and note a finished job, stop if a job lives (flock probe plus heartbeat age), list units from the registry,
  include/exclude (case-folded glob, exclude wins), state-only cooldown filter, measure within a budget of a quarter of the
  call timeout, due rule from the state module, rank most behind first (unmeasurable sorts last), claim (attempt recorded
  BEFORE the work), start the job, write the status file. Out of time keeps a cursor in the status file, so no unit starves.
- Job (feature_upkeep_job): detached, own session, all stdio on the null device, allowlisted environment (machine variable,
  explicit call timeout, prompt pins, no run id). It holds an exclusive lock for its life and runs the pass as a child under
  the bounded runner: wall-clock cap (verify timeout plus a stated margin), either stop file (never deleted), lifeline,
  heartbeat touched from the runner's poll clock. Every exit path writes a final record; a crash is a failed outcome.
- The pass is handed no goal, so a filing is a no-goal finding: the ledger row has no addressee (D-28).
- Notes: written by the watcher process only (one ledger file and one cursor key in total, D-33), as the configured actor else
  the shell user (no network lookup), unaddressed, via the pass module note writer, never the loop note verb. Bounded retries.
- Windows: refused before anything is created; the refusal is recorded once in the status file.
- Doctor: rows only when the block is on or invalid (the gate reader decides); git floor through preflight(git_floor=True),
  patch-aware parse of vendor-suffixed versions, refuses below 2.34.0 and exactly 2.35.0 (reason unrecorded in the tree).
- Ceiling: one unit per tick = 96 units a day at the 900 s interval; first enable on N units drains in N ticks.
- Per-tick cost at 100 units: state reads are local files; git half is the existing measured walk (about 13 ms a unit on a
  local 2000-commit history), bounded by the budget. The GitHub half is not measured here (no network).

never skips the calls. Job: null stdio, own session, allowlist; heartbeat from the poll clock; outcome recorded and lock freed;
crash recorded; cap kills; either stop file stops and survives; second job busy; engine handed no goal. Notes: once, offline
actor, unaddressed, bounded retries. Doctor: rows only when on, hung vs idle, git floor table, floor gated in preflight list.

offline actor. Each asserts the mutant misbehaves.
