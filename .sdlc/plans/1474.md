# Plan: goal 1474 - acceptance record reaches the branch; landed root copies are cleaned

## Goal
The P1 acceptance record (and plan/research) filed in the root checkout must reach the goal branch,
and after landing the root's untracked duplicates must not block `git pull`. Doctor must say so.

## Steps
1. `work.pr()`: after the research check add `_acceptance_missing_from_branch` =
   `_phase_doc_missing_from_branch(..., "acceptance", "acceptance record")`. Same ignore-aware,
   fail-open rules. No root record filed means no refusal, so flows without one are unchanged.
2. `work.commit()`: before `git add -A`, `_copy_acceptance_into_worktree`: if the root record exists
   and the worktree lacks `.sdlc/acceptance/<name>.md`, byte-copy it (create-only, never overwrite).
   Skipped when the repo ignores the path (`git check-ignore -q` semantic via the same helper).
3. `work.finish()` on a confirmed merge: `_clean_landed_root_records` (fetch once, best effort). For
   each of plans/research/acceptance: the root copy is removed with Path.unlink only when it is
   untracked AND its blob id (`git hash-object`) equals `git rev-parse <remote>/<base>:<path>`.
   Differing or unlanded copies are left and reported in the returned message. Files only, never
   directories. Registered in docs/launch/write-surface.json.
4. doctor: `_stale_untracked_records` row (older than one day; landed duplicate vs on no branch) and
   tracked-but-modified `.sdlc/features` files in the existing unit-records row, with the commit
   command from docs/branching-model.md section 15.
5. Docs: running.md names the gate; b6 retention doc note; CHANGELOG line.

## Test list
- pr refuses when the root acceptance exists and the branch lacks it; passes when tracked, ignored,
  unreadable ignore rules; silent with no root record.
- commit copies the record once, never overwrites a differing worktree copy.
- finish(merged=True) on a real temp repo: identical untracked copies removed, differing kept and
  reported, tracked kept; `git pull --ff-only` then succeeds.
- doctor rows for old untracked records (both classes) and modified features files.
