# Plan: heading-aware CHANGELOG union, gated (#943)

Goal: Level 1 of branch-upkeep part B, slice 2. A heading-aware sibling of the CHANGELOG union, chosen
inside `work.rebase` only while part A's gate is open. Closed gate: every existing path byte-identical.

## Files
- `skills/sigma-loop/scripts/work.py`: add `_union_headed`, `_union_for(config)`; `_try_union_changelog`
  and `_union_rescue` take `union=` (default `_union_diff3`); `rebase` passes `_union_for(config)`.
  `_union_diff3` is not edited.
- `tests/test_union_headed.py`: new, real git.
- `docs/launch/write-surface.json` and `docs/launch/write-surface.md`: gate text of the
  `_try_union_changelog` row (count stays 1, no new write site, no new delete or push).
- `CHANGELOG.md`: one entry on its own lines.

## Behaviour
- `_union_headed(text)` has the same contract and proof as `_union_diff3` (every hunk a pure two-sided
  insertion, empty diff3 base, identical inserts de-duplicated). When ours carries a heading and the hunk
  sits under `## Unreleased`, the unit's lines go above ours' first heading, with a blank line kept.
  Otherwise legacy order.
- Parks (returns the failure pair) on: a `## ` line that is neither `## Unreleased` nor `## X.Y.Z` with an
  optional dash suffix; a link-footer line; a heading on the unit's side; a heading in ours with no
  `## Unreleased` above the hunk.
- `_union_for(config)` asks `feature_upkeep.conflict_level` (the only reader of the block); any doubt,
  including an exception, returns the legacy union.
- The unit path's Level 1 loop is slice 5 and is not touched here.

## Check list
- Release-cut shape: entry lands under Unreleased with the heading apart; legacy lands under the version.
- Same non-blank line multiset as the legacy union on several shapes.
- No heading in ours: identical result to the legacy union.
- Unrecognised shapes park (bracketed heading, unit-side heading, unknown section, link footer, none above).
- Edited base, two-way markers, no conflict: park exactly like the legacy union.
- De-duplication of identical inserts.
- `_union_diff3` source hash pinned; `union=` defaults are the legacy function.
- `_union_for` over empty, partial, off, string-typed and invalid configs returns legacy.
- Closed gate, byte-identical to legacy through the in-pass replay, `ensure_fresh`, `_reconcile_behind`
  and `rebase` directly (real git, pushed file read back).
- Open gate through the same four: entry under Unreleased.
- Open gate with an unrecognised upstream heading: deferred, remote tip unchanged.
- Re-anchor and the done check accept the headed output.

## Risks
- Placement is a function of headings, not content; shapes outside the grammar park rather than guess.
- A clean replay can still misfile an entry (recorded, not handled here).
- Goal-branch push happens before part A's backup exists: single-writer branches, the existing
  replay-loss and push-refusal checks still run, and the lines are the same multiset.
