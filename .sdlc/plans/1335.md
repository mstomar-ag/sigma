# Plan 1335: pick-time upkeep honours units.include / exclude

## Behaviour
The include/exclude filter (`feature_upkeep_sched.selected`) is applied only by the scheduler. The pick-time pass (`work.py start` -> `feature_rebase.upkeep`) never calls it, so an excluded unit is still brought forward. Change: at the top of `feature_rebase.upkeep` (pick path only, i.e. when a goal is given) read the upkeep settings; when the unit is not admitted by `selected([unit], include, exclude)`, return a neutral outcome without touching the remote. PROVISIONAL (owner to ratify): the smaller design (apply the filter) rather than documenting the limit. Defaults (no include, no exclude) admit every unit, so behaviour is unchanged.
