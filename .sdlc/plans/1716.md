# Plan: session upkeep accepts a delete resolution under a replacement proof

## Goal
In session-mode Level 2 upkeep, a delete resolution is resolved, not parked, when the Decision comment's proofs and the
independent review pass. A delete that loses lines the other side added is still refused.

## Research
- `skills/sigma-loop/scripts/feature_upkeep_level2.py` `resolve_stop`: unit-line-dropped and base-line-dropped proofs run
  per conflicted file; a deleted file is `None` in `resolved_text` and compares as empty text.
- `feature_upkeep_review.py` builds the reviewer brief; `feature_upkeep_resolution.py` stamps the commit and writes the record.
- `feature_rebase.py` `_rebase_feature` has a path-level guard (`dropped_paths`) that would refuse any accepted delete.

## Design
- Which side deleted is read from the stop's stage map: stage 2 absent = integration side deleted (rule 1); stage 3 absent = unit deleted (rule 2).
- Rule 1: unit-added lines must appear elsewhere (other conflicted files as resolved, and files the replayed commit touched,
  read from the index), or be listed in `dropped-by-delete.txt` in the session's stop context (`## <path>` then one line per row).
  Listed lines go to the reviewer brief as a `dropped-by-delete` block with a prompt that approves only on explicit acceptance.
  Otherwise refuse `unit-line-dropped` naming the unaccounted lines.
- Rule 2: integration-added lines must appear elsewhere; no list is read. Otherwise `base-line-dropped`, as today.
- Rule 3: the list is put in the stamped commit message (a `dropped by delete:` section before the stamp) and in the record
  field `dropped_by_delete`. Both absent when nothing was dropped, so existing paths stay byte-identical.
- The path guard skips only paths the proofs accepted as deletes.

## Files

## Test list
- rule 1a: unit lines moved to another file, delete stands, one push, backup ref, no list in message.
- rule 1b: lines listed and review approves: pushed once; record and commit message carry the list; reviewer brief shows it.
- rule 1b: reviewer rejects the list: parked, nothing pushed.
- rule 1: lines neither moved nor listed: parked naming them.
- rule 2: unit deleted, integration lines lost, a list offered: refused `base-line-dropped`.
- rule 2: integration lines found elsewhere: delete stands.
- Each clause broken once and seen red; neighbours: upkeep session, level2, resolution, review, write-surface.

## Done when
All of the above pass and the existing upkeep tests are unchanged.
