## Behaviour
1. Reclaiming a stale lease whose pid was reused must not call `take_footprint(pid)` (it would measure a foreign process and feed its size into the cost ring). `_finish` for a reused record uses only the stored `peak`.
2. `process_start` returns seconds on both platforms: on Linux divide /proc starttime ticks by a `clock_ticks()` seam (os.sysconf SC_CLK_TCK, fallback 100). START_TOLERANCE stays 2.0 seconds.
3. `wait` applies the same gates as `_choose`: `limits.admits(kind, running=len(live))` for goal/session and the `max_goals` cap for goal.
4. `wait` and `_choose` read `r.get("goal")` so a lease record without a goal key does not raise.
