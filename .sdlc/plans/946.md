# Plan 946: Level 3 parks, the capped brief, per-conflict findings (part B, slice 6)

## Approach
Behind the existing upkeep gate only. A unit conflict that nothing resolves becomes a park: the stop is described
(identity plus a capped brief) at the conflict stop, before the scratch worktree is dropped; the pass reports the new
`parked` outcome; one finding per conflict is filed through a no-goal path in the filing helper; the filed store gains
a record value; a later clean pass closes the finding through `gh_api`. With the gate closed nothing changes.

## Files
- skills/sigma-loop/scripts/feature_park.py (new, pure): conflict identity, neutraliser for marker strings and kit
  paths, capped brief builder, filed-store record helpers, close rule. Reads no configuration, joins no path.
- skills/sigma-loop/scripts/feature_rebase.py: `PARKED` outcome and wording, `.rebase-parked.json` marker with its own
  path builder, `_describe_stop` (in the replay, before the drop), `_file_park`, `_settle_parks`, `_forget`; the
  told-before check reads old and new store values.
- skills/sigma-loop/scripts/handoff.py: `goal=None` path and `idempotency_key` argument.
- skills/sigma-doctor/scripts/doctor.py: open-park row with age, read from the new marker.
- tests/test_feature_park.py (new); tests/test_feature_rebase_hygiene.py (one outcome updated from conflict to parked).
- docs/launch/write-surface.json and docs/launch/write-surface.md: rows for the new close and comment sites and the
  marker delete.

## Behaviour
- Gate open and a stop with unmerged paths: outcome `parked`, report carries the park info. Gate closed: `conflict`, as before.
- Identity is a hash of unit, patch-id (merge: subject and rev count), sorted paths; the tip is not part of it.
- No-goal filing: no unit lookup from a goal, no metered classifier, no ownership verdict (so no note to an owner), no
  goal comment or body marker, no fuzzy duplicate search, ledger note unaddressed and keyed on the scoped key, upstream
  routing keyed on the scoped key; the key rides in the body as an inert line.
- Store: park slots hold a record of fingerprint, issue number and reused flag; other slots stay plain strings.
- Settling happens on a pass that is current or rebased cleanly, gate open only: marker removed, record comment posted,
  then the issue closed, unless reused or shared with a live slot; a failed close keeps the slot for the next pass.

## Check list
- Identity is stable across tip moves and path order, and differs per commit, file set and unit; merge uses subject and position.
- Every registered marker, in both spellings, is broken by the neutraliser (control: the raw text is honoured by the reader).
- Kit paths are withheld from the brief and from posted text; ordinary paths stay.
- The brief obeys its file, commit, byte and time caps, keeps its more-files footer, and makes no gh call.
- No-goal filing: no lookup, classifier, ownership verdict or duplicate search runs (each patched to raise); the ledger note
  is unaddressed and nobody is told; routing sees the scoped key; two templated findings never collapse onto one issue.
- Engine, real git: gate open gives `parked`, remote and checkout unchanged, one filing, store record, own marker; second
  pass and a moved tip file nothing more.
- Gate closed: `conflict`, goal-keyed filing without the new arguments, string store value, no park file, no close call.
- Clean pass after a hand resolution: comment before close, no issue reference in the comment, slot and marker gone; a
  failed close keeps the slot; a reused issue is never closed; gate closed never settles.
- Doctor row appears only with a marker, never as a would-drop row, silent when upkeep is off.
- Existing pins stay green unchanged: the unit-argument pins in the stamp and filing tests, the store-key pin, the
  totality pin on outcomes and wording.

## Controls
Break each guard once and see red: drop the neutraliser; reintroduce the tip into identity; re-enable the duplicate
search on the no-goal path; remove the reused check in the close rule; close without the shared-issue check.

## Risks
- Defaults provisional: caps of 12 files, 3 commits, 1200 bytes per excerpt, 8000 bytes, 20 s.
- Closing on the landed-unit condition is not wired; only a clean pass closes (the store is per machine).
- The idempotency key is not searched for on the tracker; repeat filing is prevented by the per-machine store.
