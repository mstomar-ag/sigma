# Plan 1399: transient auth failure never yields a login instruction

Files: skills/sigma-init/scripts/setup_wizard.py, tests/test_setup_wizard_transient_auth.py (new), CHANGELOG.md (Unreleased).

Behaviour: `_only_auth_failing` currently needs the failing wizard rows to equal the single row "gh auth". With a project board on, the "gh project scope" row also fails when auth is unconfirmed, so the transient path (one retry, then the "could not confirm" step cached for a short window) is skipped and the hook advises `gh auth login`. Change: the failing set must contain "gh auth" and otherwise only "gh project scope". Any other failing row, or scope alone, keeps today's path.
