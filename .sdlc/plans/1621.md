# Plan 1621: one map read and one unpark sweep per batch

## Files
- `skills/sigma-loop/scripts/loop.py`: `next_batch`, `_next`, `_next_untraced`, `_dag_order_pick`.
- `skills/sigma-loop/scripts/dag_order.py`: `ChainRanks.mark_in_flight`.
- New `tests/test_batch_one_read_1621.py`; CHANGELOG line under Unreleased.

## Behaviour
- `next_batch` builds `batch = {"map": {}, "unparked": None}` and passes it to every `_next(..., batch=batch)`. `batch=None` (CLI `next`, refills) is today's code path exactly.
- With a batch, `_next_untraced` skips the per-call `_dag_first_pick`, `_dag_check_pick`, `_dag_order_pick` and `_reconcile_sweep` (the prologue ran them) and runs `_auto_unpark_sweep` only on the first slot call, keeping its result in `batch["unparked"]`; every slot folds that set into its skip (cooldown kept). Lazy, so a FULL or gated batch still sweeps nothing.
- The prologue's `_dag_order_pick` takes `cache=batch["map"]`, so `dag_order.chain_ranks` loads the map once; the per-call `gate` dict is seeded from `batch["map"]["dag_pick"]` and copies it back after the first hold lookup, so `dag_pick` reuses the same load.
- After each pick `next_batch` calls `ranks.mark_in_flight(goal)` (drops edges whose blocker is that goal from the view, clears the memo).
- Waves: no code; test that skipping all but wave 0 of `dag_chain.chain(...)["waves"]` makes the picker return exactly wave 0.

## Test list
- three-slot batch: counting fakes show one `_auto_unpark_sweep` call and one `dag_store.load`; `_next` alone sweeps once.
- two independent chains give their two roots; a dependent of the in-flight root is not offered.
- a goal returned by the sweep is not picked in the same batch.
- parallel.goals off: single slot, same result as before; work.enabled off message unchanged (existing tests).
- wave-0 skip test.
- gate closed (mode off / local source): `dag_order` not loaded in a batch.

## Risks
- Skipping the per-call check in a batch: prologue already ran each; a standalone `_next` unchanged.
- Controls (each clause alone): per-call sweep back in; map cache not shared; unparked set not folded; per-call order pick back.
