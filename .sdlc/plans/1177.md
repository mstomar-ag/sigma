# Plan 1177: watch comparison at every human decision

Goal: the autonomy ladder can climb through real gestures. Wire `autonomy.record_watch` into the record writers.

## Files
- `skills/sigma-loop/scripts/decision_record.py`: add `would_for(sdlc_dir, record, config)` (BEFORE the store append) and `record_comparison(sdlc_dir, record, would, config)` (AFTER a successful append); call both inside `write_all` for how == human.
- `skills/sigma-loop/scripts/handoff.py` `_record_ack`: same two calls around its own append.
- Tests: new `tests/test_watch_wiring.py`; CHANGELOG Unreleased line. No new write site (reuses `autonomy.record_watch`); no SKILL.md text.

## Behaviour
- would = sealed approved rule's option (`rulebook.match`, hard-stop kinds never match); else the unique majority of earlier human choices for the same kind and area once at least `l1_min_answers` exist; else None (no comparison written, never a disagreement).
- Computed before the person's record is appended, so the answer is not in its own majority.
- Only when `autonomy.enabled` and records enabled; skipped for how != human and when record visibility is public (the watch file would carry free text; PROVISIONAL, mirrors the draft verb's refusal).
- Any error is swallowed; the watch file is written only if the store append succeeded.
- Hard-stop kinds: comparison recorded; `autonomy._state` already caps at 2.
- Cost per gesture: one rule match plus one list_by read plus one small file; list_by uses the index, so about 1 ms at 100 answers, linear scan of one kind at 10x/100x (state measured number in the PR).

## Test list
1. Gate closed (autonomy off or records off): no watch file, same bytes.
2. Rule match gives would; majority needs enough answers; none writes nothing.
3. Store failure writes no watch file; watch failure does not fail the gesture.
4. Hard-stop kind records comparison, level capped at 2.
5. End-to-end through the real unpark verb: 14 answers reach level 2 and rule_draft lists the pair; with the wiring disabled it stays at level 1 (seen red).
6. Ack path and promote/demote path each write one comparison.

## Risks
Public visibility leak (skipped). Majority self-inclusion (computed before append). Registry/inventory tests: no new writers.
