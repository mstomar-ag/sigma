# Plan 1563: quota park records reset_at; unknown waits the window

## Goal
A quota park whose reason names a reset time or retry-after records `reset_at` on the park and on the applier ask.
When no reset is named, the ask waits for `rulebook.autonomy.applier.window_minutes` (no fixed 24h fallback).
Docs and CHANGELOG say exactly that.

## Design
- `qkind.py` gains a pure tolerant parser `parse_reset(text, now)`: understands `Retry-After: N` (seconds),
  `resets in N seconds|minutes|hours`, `resets at <ISO time>` / `resets at <epoch>`, and a rate limit reset epoch
  (`x-ratelimit-reset: <epoch>`). Unparseable gives None, never raises; a time not after `now` or more than
  7 days ahead gives None. Plus `render_reset_line` / `parse_reset_line` for the machine line
  `sigma-reset-at: <iso>`.
- `loop._record` (parked, quota kind): parses the detail, appends the reset line BEFORE the qkind line (the qkind
  line stays last), and hands `reset_at` to `applier.open_for_park`.
- `applier._park_info` reads the reset line off the park comment so the sync path records it too;
  `open_for_park` passes `reset_at` to `open_ask`.
- `applier._quota_wait_pending`: pending only while a recorded `reset_at` is in the future (or unreadable);
  no `reset_at` means the ordinary window rule alone governs (window_open). The 24h constant is removed.
- Closed gates (applier off, non-quota kinds): park text and asks stay byte-identical.

## Test list
1. parse_reset: retry-after seconds, resets in minutes, ISO resets at, epoch; garbage, past, over 7 days, huge ints -> None.
2. A parsed reset is honoured: ask with reset_at holds past the window, applies after.
3. Unknown waits for the window: no reset_at, applies once window_minutes passed, not at 24h; not before.
4. Scenario through the real verb path: `loop.py record parked --qkind quota` with "Retry-After: 7200" on a temp
   repo with fake gh; park comment carries the reset line before the qkind line; ask file has reset_at; tick holds,
   then applies.
5. Closed gate / non-quota: park text byte-identical (no reset line) for applier off and for non-quota kinds.
6. Rewrite the old 24h test (test_legacy_block_quota_window_1522) to the window behaviour.
7. Neighbours stay green: applier, qkind, write-surface, no-direct-gh, changelog/docs tests.
