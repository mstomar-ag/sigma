## Behaviour
- `how_for(gesture)`: sweep is autonomous, every other gesture human; unknown gesture raises.
- `build(...)` returns a plain dict (qkind, choice, reason, how, gesture, issue, rule_id); unusable qkind reads `unknown`, empty choice reads a placeholder. No person field.
- `write_all(sdlc_dir, record, config, source, text="", poster=None)`: closed gate returns a no-op report and writes nothing. Open: append to the store (catching any error), then post `text` plus a fenced decision span (same id, redacted when the repo is public) through the source helper (`_issue_comment`, or the given poster). A store failure still posts the comment and returns the error text.
- Callers keep the old code path when `decision_record.enabled(config)` is false; when true they route their comment through `write_all`.
- `acknowledge` writes only the store record (the ack is a ledger entry; no issue is touched).
