# Plan: lease-table fixes (#1715)

Goal: four defects in `skills/sigma-loop/scripts/resource_lease.py`, each fixed test-first.

## Research
- `_stale` = dead pid or expired ttl; no check that the pid is still the same process.
- `wait` checks `goal_block` only; `admit` (`_choose`) also holds a goal while a started goal's verify waits.
- `_finish` reads `record["id"]` / `record["kind"]`; `_load_one` only demands kind and pid.
- `wait --max` takes any float; nan makes `min/max` arithmetic undefined, negative is silently 0.

## Steps
1. Seam `process_start(pid)`: libproc on macOS, `/proc/<pid>/stat` field 22 on Linux, None when unreadable. No child process.
2. `admit` records `pid_start` in the lease; `reused(record)` compares it with the current reading (tolerance 2 s); `_stale` adds it. Leases without `pid_start` are never judged reused (old files unchanged).
3. `wait`: for kind goal, not open while any waiting goal is among the started (leased) goals.
4. `_finish`: `record.get("id")` falling back to the file name, `record.get("kind", "unknown")`.
5. `wait()` raises ValueError on nan or negative; the CLI `--max` type rejects them through argparse (exit 2, message names the value).
6. CHANGELOG line under Unreleased.

## Gates closed
No reuse data, no waiting verify, valid ids, valid `--max`: behaviour identical (existing tests unchanged and green).

## Test list
- reused pid reclaimed (injected start time); unchanged start kept; real `process_start` stable and None for a bad pid.
- wait goal holds with a started goal's verify waiting; session kind unaffected; clears after the verify is admitted.
- release of an id-less lease file returns True, file removed.
- CLI `wait --max nan|-1|-0.5` exits 2 naming `--max`; library `wait` raises ValueError.
- Neighbours: test_resource_guard, test_resource_guard_limits, test_write_surface, test_script_help.

## Scale and recovery
Per-lease cost is one /proc read or one libproc call per admit; leases are few. A failed read means no reclaim (fails safe: keeps the lease, ttl still bounds it).
