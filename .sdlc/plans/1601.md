## Behaviour
1. mode off: verify path and evidence file byte-identical (golden test).
2. Otherwise: admit(kind verify, want workers). Hold -> exit 5, stderr `RESOURCE-HOLD ...` with retry_after, no evidence file, ledger and action-log event; record done still refuses.
3. Run in its own process group with lifeline and wall-clock timeout from verify.timeout_minutes; output bounded by the tail ring.
4. Workers: `{workers}` token (integer only, injection-safe), env `SIGMA_VERIFY_WORKERS`, env `PYTEST_XDIST_AUTO_NUM_WORKERS` only if proven against the installed xdist (else removed and the test says so). A literal `-n N` leases N.
5. Learned cost: sample the child tree footprint during the run, record peak divided by workers via resource_lease.record_observation; release the lease in finally.
