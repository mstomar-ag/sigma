- create `tests/test_autonomy_visible.py`; CHANGELOG line.

## Behaviour
- Thresholds in force come from `settings(config)`; the next requirement for level n is level n+1's answers, comparisons and agreement (level 0 needs only the level 1 answer count).
- Wording is built in one place (`describe`), so the doctor and the question list cannot drift apart.
- Hard-stop kind: says it never learns beyond level 2 and is always asked.
- Gate closed: `readout` stays `{"enabled": False}`, the doctor row stays `off (default)`, `brief` has no new key and `render_brief` no new line.

## Test list
- readout rows carry answers, answers needed, comparisons, agreement
- no records: one line, learning has not started
- below level 1: the count line
- level 1 with too few comparisons
- capped hard-stop kind wording
- unpark brief line below level 1 with the count
- gate closed: doctor row, readout, brief and render are byte identical (control: open the gate, see red)
