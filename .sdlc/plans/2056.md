# Plan 2056: a unit view for the dependency map

Goal: `dag.py report --feature <unit>` and `dag.py html --feature <unit>` show one unit's members and,
labelled as outside context, every open blocker of a member that sits outside the unit; `/sigma-dag`
documents it and declares an `argument-hint`.

## Files
- `skills/sigma-loop/scripts/dag_report.py`: `report(..., feature=None)`; a unit branch after the `_fix` check.
- `skills/sigma-loop/scripts/dag_html.py`: `run(..., feature=None)`; a `build_unit` that merges the per-member
  chain models (`build`) for the unit's end members into one model, nodes outside the unit tagged outside context.
- `skills/sigma-loop/scripts/dag.py`: `--feature` on `report` (not with `--goal`) and on `html` (in the
  required group with `--goal`/`--all`).
- `skills/sigma-dag/SKILL.md`: `argument-hint`, `--feature` lines (offset any added sentence by trimming).
- `docs/dag.md`, `CHANGELOG.md` (`## Unreleased`), registries touched by script help.
- tests: `tests/test_dag_unit_view_2056.py`.

## Behaviour
- Members: stored nodes with `unit == <unit>` that are open issues. Outside blocker: an OPEN blocker (edge
  blocker->member) whose node has a different or no unit. Each member lists its open blockers, each marked
  `(outside unit)` when outside; a "## Outside blockers" section lists them once with their unit/life.
  A blocked member is never printed without its blockers.
- Unknown unit (no node carries it): exit 2, ONE line naming the units the map knows. Known unit (map has
  nodes of it) but no open member: says so in one line, exit 0.
- `--json`: same `dag-report/1` schema plus `feature`, `members`, `outside`.
- html: one page `unit-<unit>.html` under the out dir, path printed, same refusals; outside nodes drawn muted
  with a legend entry.
- Reads the stored map only; no network, no write (report).

## Test list
- report md/json: members only plus outside blockers labelled; control: drop outside blockers -> red.
- blocked member never free in the filtered view (blocker outside); per-clause: only-open blockers (a closed
  outside blocker is not shown), label present, members filter.
- unknown unit refuses one line listing units; known unit with no open members says so.
- html unit page written, path printed, contains the outside blocker marked outside; refusals same.
- argparse: `--feature` with `--goal` refuses; html needs one of goal/all/feature.
- SKILL.md frontmatter has argument-hint; context-budget ratchet, script help, skill-card tests stay green.

## Risks
- Shared render code assumes one `goal`; the unit page must not break chain pages (existing html tests).
- Context-budget ratchet: offset the added SKILL.md sentences.
