# Plan 1990: deps.py report shows reverse waits and quoted markers

Feature: dag-views

## Files
- skills/sigma-loop/scripts/deps.py:
  - `REVERSE_READ_MAX = 10`. `report(source, goal, max_reverse=REVERSE_READ_MAX)`: after `analyse`, for refs with read_as edge/comment-edge/weak (rank order, then number, first `max_reverse`), read that ref once with `_read` and run `analyse(ref, ...)` on its text; `reverse: true` when the goal appears there as edge/comment-edge/weak, else `false`. Refs not read get no `reverse` key. A ref whose read fails gets `reverse: null`. Output gains `reverse_reads: <n>` and `reverse_unchecked: [refs]` (the eligible refs beyond the bound). Pure `analyse` is unchanged for callers that do not pass reverse data.
  - `analyse` marks an explicit BODY edge `quoted: true` when the sentence before the blocking phrase names another issue or slice as its subject: a slice code (`S` plus digits), `#M`, or the word slice, followed within the same sentence by carry/carries before the phrase. A line starting with the phrase (the goal's own marker line) is never quoted. Only body edges carry the key.
  - USAGE/docstring: describe the two flags, that they are advisory, and the cost: at most `REVERSE_READ_MAX` extra issue reads (each one read plus ceil(comments/100) comment pages) per goal; at 10x refs the cost stays bounded at that number, the rest are listed unchecked. Batch (`--label`/`--chain`) multiplies by members.
- tests/test_deps_1990.py (new) with a fake source; extend neighbours only if needed (tests/test_deps_batch_1944.py fakes have `_read_issue` returning one body for every ref: a reverse read on them must not break their expectations; adjust the fakes or pass the bound as 0 only if unavoidable, preferring fakes that cannot name the goal).
