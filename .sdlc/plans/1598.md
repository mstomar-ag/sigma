## Behaviour
Memory headroom = min(available - reserve - unmaterialised leases, share_cap - leased footprint). Hold when headroom < unit cost; resume when >= cost + one session cost. Pressure 2 (or PSI above derived) blocks goal starts but admits one verify worker; pressure 4 or available < reserve/2 = critical. Bad config values (negative, bool, str, NaN, 0, 1, >=1 fractions) = derived + note.
