## Design (the exact shapes the tests pin)

**`blocker_scan.extract_local_refs(text)`** -> ordered, deduplicated list of
`{"phrase": str, "ref": str, "kind": "id" | "stem" | "foreign"}`.
1. `t = strip_unpark_qa(text)` (same first step as `extract_refs`).
2. Numeric pass: `_EXPLICIT_BLOCK_RE.finditer(t)` (the SAME compiled pattern, no new vocabulary).
   `is_cross_repo(t, m)` -> kind `foreign` with ref `m.group(2)`; else kind `id` with ref
   `str(int(m.group(2)))` (so `#0007` and `#7` are one key).
3. Stem pass, marker line only: `_MARKER_LINE_RE = re.compile(r"(?im)^[ \t]*(?:[-*][ \t]+)?\*\*blocked by:\*\*[ \t]*(.*)$")`.
   Value split on `,`; each item stripped of whitespace, backticks and one trailing `.`; a
   trailing `.md` removed. Item is a stem ref iff it does not start with `#`, `_STEM_TOKEN_RE =
   r"[A-Za-z0-9][A-Za-z0-9._-]*"` fullmatches it, and `item.lower()` is not in
   `NULL_MARKER_VALUES = ("none", "nothing", "nil", "na", "tbd")`. A pure-digit item becomes kind
   `id` (`str(int(item))`); otherwise kind `stem`, ref = the item verbatim. Items with whitespace
   (prose), `/`, `#` or `:` are never stems.
4. Dedup on `(kind, ref)`; phrase is the lowercased trigger (`blocked by` for the stem pass).
No self-ref parameter: self-reference is decided after resolution (step in loop), because `0007`
vs `7` vs the stem `0007-x` cannot be compared as strings.

**`discovery.goal_index(goals_dir)`** -> `{key: [(path_str, status), ...]}` over
`sorted(Path(goals_dir).glob("*.md"))`, only files whose frontmatter has a `status` (README.md is
not a goal, same rule as `next_pending`). Keys per file, deduplicated per path: the stem; the
leading digits of the filename as `str(int(...))`; frontmatter `id` as `str(int(...))` when it is
all digits. Paths are `str(path)` from the same glob shape `next_pending` returns, so equality
with the candidate `goal` is a plain string compare.

**`loop._is_local_source(source)`**: `isinstance(getattr(source, "goals_dir", None), str) and
callable(getattr(source, "fetch_title_body", None))`.

**`_pick_dependency_hold` seam** (line ~1669) becomes:
```python
if not mirror.is_github_mode(config):
    if _is_local_source(source):
        return _local_dependency_hold(source, goal, mirror, cache)
    return ""                      # a non-file, non-github source: unchanged from before
```
Mode-off check above it is unchanged, so `dependency_gate.mode: off` disables the local gate too.
The outer `except` (claim + `dependency gate failed non-fatally`) is reused unchanged: an
EXCEPTION fails open exactly as in GitHub mode; an UNRESOLVED REF fails closed (owner decision).

**`_local_dependency_hold(source, goal, mirror, cache)`**:
- `refs = mirror.blocker_scan.extract_local_refs(source.fetch_title_body(goal).get("body") or "")`;
  no refs -> `""` with NO index build (the common case costs one file read + one regex scan).
- `cache["local_index"]` built once per `_next` call via `sources.discovery.goal_index(source.goals_dir)`,
  lazily on the first candidate that has refs. The `gate` dict is per `_next` call, so the next
  pass always rebuilds it: that is the whole release mechanism.
- Per ref, `shown = "#" + ref` for `id`/`foreign`, `ref` for `stem`; `hits` = index entries for
  the key with `path != goal` (self-reference dropped; a ref whose only hit is the goal itself is
  silently dropped exactly as `extract_refs(self_ref=)` drops one in GitHub mode).
  - `foreign` -> hold `"%s (blocked by — another repository, not a local goal)"`, added to `unresolved`.
  - no entries for the key at all -> hold `"%s (blocked by — no such local goal)"`, added to `unresolved`.
  - more than one distinct path -> hold `"%s (blocked by — matches %d local goals)"`, added to `unresolved`.
  - one hit whose status is not `done` (pending, in_progress, parked, failed, proposed) -> hold
    `"%s (%s)" % (shown, phrase)`, the GitHub item shape.
- If `unresolved`: one stderr line, `loop.py: <stem> names prerequisite(s) <list> that resolve to
  no single local goal under .sdlc/goals — HOLDING it rather than ignoring them; fix the marker or
  file the goal (or set discovery.dependency_gate.mode: off)`.
- Returns `", ".join(holding)`. Zero `gh` calls (no `run`, no mirror fetch in local mode).

**Hold line, mode-aware, GitHub byte-identical.** `_hold_subject(source, goal)` -> `("#%s" %
goal, "still sdlc:goal")` for any non-local source (today's literal bytes), `(Path(goal).stem,
"still status: pending")` for a local one. `_next` prints `"loop.py: not claiming %s — open
prerequisite %s. Left untouched (%s, no claim); taking the next candidate"` and appends
`(subject, hold)` to `held`; the DONE summary formats `"%s → %s" % h` (the `#` now lives in the
subject). For GitHub this renders exactly `not claiming #1595 — ... (still sdlc:goal, no claim)`
and `#1595 → #1594 (blocked by)`, which the unchanged GitHub tests assert.

**`state.release`**: `if _status(goal_path) in _TERMINAL_STATUSES or _status(goal_path) ==
"proposed": return False` (read once into a local). `_TERMINAL_STATUSES` is NOT widened (it
mirrors discovery's terminal set and is documented as such). Docstring gains one sentence: a
`proposed` goal is a human-promotion gate, release is a claim-undo, a proposed goal was never
claimed. `LocalSource.release` journal string becomes `"...already done/parked/failed/proposed —
no change made"` (keeps the substring `test_loop.py` asserts on the CLI line, which is a different
string in loop.py and is untouched).

## Scale

Per `_next` call in local mode, added cost: one `fetch_title_body` read + one regex scan per
candidate offered; plus, only when some candidate declares a ref, one `goal_index` pass (N file
reads) cached for the call. Zero `gh` calls, zero writes. `next_pending` already reads all N files
per candidate and `_next` re-calls it once per held goal (TD-4: O((H+1) x N) reads per pick), so
the gate adds at most one more N pass per call: at 10x (~500 files) and 100x (~5,000 files) the
gate's share is 1/(H+2) of the pick's file reads, and TD-4, not this change, is the ceiling.
Step 7 measures absolute times; until then this is unmeasured, and the PR must say so if Step 7
is skipped. `next_batch` builds one index per slot (each `_next` has its own `gate` dict): K slots
-> K passes, bounded by `max_concurrent`.

## Risks

1. Fail-closed on a phantom marker stalls a goal. Mitigations: stems only on the canonical marker
   line, single-token, null words excluded; every hold is named; levers are editing the body or
   `dependency_gate.mode: off`.
2. Existing local backlogs whose bodies cite GitHub numbers (`**Blocked by:** #1499` copied from an
   issue) now hold, named `no such local goal`. Intended per the owner decision; called out in the
   PR body.
3. `handoff.py track --blocks yes` already writes `**Blocked by:** #<child>` onto the calling goal
   (`handoff.py:1170-1172`): after this change a released or re-pended parent is held until the
   child is done (desired; BR-16), and sigma-scope's local `compile_plan` chains become ordered.
4. Triage may park a child (deny-list, `ai_filed.max_per_goal`); its dependents then hold with the
   prerequisite named — visible, not silent.
5. Hold text for local reuses the GitHub words "open prerequisite" and "when it closes" in the DONE
   summary — same shape by design (acceptance), slightly GitHub-flavoured wording.
