# Plan: upkeep part A, slice 8 (documentation, opt-in audit, one local end-to-end run)

## Goal
Close part A: user documentation and the config reference for the scheduler, backups, restore and prune; an opt-in audit that
enumerates every part A entry point without trusting the registry; one end-to-end run on a local scratch bare remote with a
short evidence record. Nothing claims the feature is proven on a hosting service.

## Steps
1. Audit test `tests/test_upkeep_audit.py`. An enumerator that finds gate use by any spelling (decorator, aliased import,
   assignment form, hand-written reader call, a loader helper that names the gate). Controls on hand-built sources for each
   hole of the registry guard. Equality with the registry and the drivers. A list of known hand-written readers, each with
   a reason, with unknown and stale entries both red. The near-enabled matrix per real driver, an enabled control per driver
   (the result is not the closed one), and a stripped-decorator mutation seen red per driver.
2. End-to-end test `tests/test_upkeep_local_run.py` on a bare remote in a temporary directory: pass 1 rewrites and backs up,
   restore from a fresh clone, pass 2 shows a restore is not sticky, dry-run prune then prune keeps the newest and leaves the
   unit branch and base. Only the clock is set; no model, no hosting service. Its transcript is compared with the committed
   record.
3. Record `docs/launch/evidence/upkeep-local-run.md`: says plainly local bare remote only, not proven on a hosting service.
4. Docs in `docs/branching-model.md`: sections 13d (scheduler, one opted-in machine per set of units, levers, ceiling,
   what is and is not proven), 13e (config reference, one row per key), 13f (how existing adopters pick up rule edits),
   and the prune sentence in 13c. One README flag row. One CHANGELOG line.

## Hygiene traps handled
No home or temporary paths, e-mails or URLs; only Sigma named; every backticked path exists; no square bracket expression
directly followed by a parenthesis; documented script gestures unchanged; no release-shaped numbers; no citation of private
plan files; the config table sits in a fence with a delimiter row.
