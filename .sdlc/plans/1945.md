## Behaviour
Live holder, any one of: (a) `loop._goal_has_registered_worker` true (agent-start marker with live pid, this machine); (b) ledger enabled and the goal is in `ledger.open_claims(read_all, ttl_seconds=lease_ttl)` (any actor, unexpired lease).
Stale: label present and (ledger enabled and no open claim and no live worker) or (ledger disabled and the local marker is definitively "dead"). Ledger disabled with no marker = unknown = stays in progress (cannot tell another machine's work from a leftover; conservative default, PROVISIONAL, owner to ratify). Any read exception = stays in progress (fail closed toward the old behaviour). Ledger read once per plan, only when a member carries the label (O(ledger) cost, bounded to one read).
The map-built path (chain.py ~l.458, `raw == "in-progress"`) is left as is; the live path is the one the planner uses with labels.
