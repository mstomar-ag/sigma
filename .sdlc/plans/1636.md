## Output contract (decision 6)
Line 1: `proxy: counts reverts and fix-subject commits that touch a goal's files; unrelated fixes and unreported defects are not counted, so this bounds no defect rate`. Line 2 header: `window=Nd mature=M immature=I unresolved=U denylist=<...>`. Then `<goal>\t<pr>\t<merged_at>\t<reverts>\t<fixes>` per mature goal. Last line: `totals reverts=R fixes=F (distinct commits) multi-attributed=K`. Unmeasured: line 1 proxy, line 2 `unmeasured: <reason>`, exit 0, no rate anywhere. Typed refusal (window > 90, < 1, not an int, unknown verb): stderr `outcomes.py: REFUSED [<code>]: ...`, exit 2, empty stdout.

## Task 6: attribution and totals (AC-1, AC-2; decisions 1, 4, 5)
11. Tests, one per clause so each can be broken alone:
   - AC-1: a revert inside 14 days of goal A's merge counts against A; a revert after 14 days does not.
   - AC-2: a `fix` touching a file A changed counts; a `fix` touching only unrelated files does not.
   - own branch: a commit on the goal's own branch (a merge-commit-method fixture with `sha^1..sha^2`) is excluded; squash branch commits are not on base so absent by construction.
   - later-goal: a `fix` whose last `(#N)` is a later goal's `pr` is skipped; a REVERT with the same marker still counts.
   - denylist: a fix touching only `CHANGELOG.md` (shared by two goals) counts for neither; touching CHANGELOG.md and a real file counts only for goals overlapping the real file; `.sdlc/x.md` and `a.lock` ignored.
   - distinct: one fix overlapping goals A and B gives one total, a row in each, `multi-attributed=1`.
   - revert target: `This reverts commit <A's merge sha>` attributes to A even with no file overlap; unresolvable target falls back to overlap.
   - ordering: topology decides, time only caps: a fix older by committer clock but later on base still counts; a fix committed before the merge (earlier on base) never counts.
   - cap: a goal with 300 files is truncated to 200 and flagged.
12. Implement `_attribute()` over the in-memory index. Green.
