# Plan 1085: a shipped caller supplies the pass's rewrite and push

## Files
- `skills/sigma-loop/scripts/feature_upkeep_pass.py`: add `unit_callables(cwd, remote, branch)` and the gated entry point `run_unit_pass`.
- `tests/test_upkeep_entry.py`: new tests on local bare remotes.
- `docs/launch/write-surface.json`: register the push and worktree-removal sites.

## Behaviour
- `run_unit_pass` is gated "project" and calls `upkeep_pass` with `rewrite` and `push` from `unit_callables`; other keywords pass through.
- rewrite: detached scratch worktree at the unit tip, `git rebase <base tip>`, remember the new sha, remove the worktree. Conflict or failure: `rebase --abort`, return `ok: False` (the pass reports failed, push does not run). The unit ref never moves.
- push: `--force-with-lease=refs/heads/<branch>:<tip read>` with refspec `<new>:refs/heads/<branch>`; never a delete. A moved remote branch is refused and the pass reports failed.
- Gate closed: the decorator returns the closed result before anything runs; equal to the plain `upkeep_pass` closed result.
- Conflict resolution stays out of scope (resolved is always False, so the push uses the clean-replay hooks policy).

## Test list
- end to end on bare remote: remote branch becomes the unit replayed on base; local ref unmoved; no leftover worktree.
- conflict: result failed, remote untouched.
- lease: remote moved after the rewrite, push raises, remote keeps the other commit (control: swapping the lease for a plain force turns it red).
- gate closed: equals plain `upkeep_pass`, no git call, no state file, remote untouched.
- existing: write-surface ratchet, never-delete scanner parity, unattended isolation, pass and wiring tests stay green.

## Risks
- Scratch worktree in the system temp dir: removed in `finally`; a killed process leaves a stale worktree entry (git prune handles it).
- Nothing calls `run_unit_pass` from the scheduler yet; the shipped entry point is the function, wiring it into the job is a separate decision.
