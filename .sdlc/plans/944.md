# Plan: the proof gate's checks as pure functions (part B, slice 3)

## Goal
The checks that decide whether a machine-resolved unit rebase may be trusted exist as pure functions, each with a
control seen red. Nothing calls them yet, so with the gate closed every existing path is unchanged.

## Files
- `skills/sigma-loop/scripts/conflict_proof.py` (new library, no CLI, reads no config): `read_commits`, `pair_commits`, `only_conflicted_differ`, `per_path_multisets`, `multiset_differences`, `check_markers`, `new_whitespace_findings`, `check_tests`.
- `tests/test_conflict_proof.py` (new): pure cases plus real-git controls.
- `tests/test_script_help.py`: the library list gains `conflict_proof`.
- `CHANGELOG.md`: one line.

## Behaviour
- Every check returns a list of refusals with a named code; empty means pass. Unreadable input refuses.
- Pairing: stop record first, else an authorship key unique in both ranges; skipped-as-upstream by patch-id (one batched process); emptied at a stop; anything else parks. Reordering parks. The key is a parameter so a control swaps in patch-id equality.
- Stage-0 form: any index entry outside the unmerged set that differs from the baseline refuses. Multiset form: added and removed line multisets per path outside the conflicted set must match the original commit; hunk placement is ignored.
- Markers: counts compared with the original blob; the middle marker counts only beside a start marker. Whitespace: only findings new relative to the original commit's own check.
- Test counter: Python only, resolved at least ours plus theirs minus base, no skip marker beyond both sides.
- The claim that range-diff cannot pair a resolved commit depends on the fixture (a one-line file failed, a 40-line file paired); the module docstring carries that qualifier.

## Test list
- Markers: leftover refused, setext rule allowed, file about markers allowed its own count.
- Whitespace: new finding refused, inherited finding allowed, moved finding allowed.
- Stage-0: engine edit outside refused, edit inside allowed. Multiset: changed neighbour refused, placement shift allowed, rename parks.
- Pairing on real git: base hotfix cherry-picked parks none; dropped commit parks; context drift passes and is red under patch-id key; twenty drifting commits park none; same-second same-subject pair parks; resolved commit pairs through its stop record; merge stop.
- Test counter: loss, identical additions, non-Python, absent resolved, skip added, non-test path.

## Risks
- The merge comparison and the authorship-key collision rate on an adopter repository are measured on scratch repositories only (D-6, D-41).
- The Python-only counter parks other languages (D-26).
