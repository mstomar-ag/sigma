# Plan: unpark.py report (goal 1561)

## Goal
`unpark.py report <dir> [--json]` lists every parked or blocked issue with its declared kind (or the
suggested one), area, matching approved rule and the rule's gesture, the pair's autonomy level, and
whether the applier would act now, later (window) or never (and why), then one total line per outcome.
Read-only: it reuses `list_parked` (same fetch), one `_fetch_issue` read per park (what `list --undeclared`
and `brief` already use), `qkind.resolve`, `loop._suggest_kind`, `decision_record.area_of`,
`rulebook.match`, `applier.option_gesture`, `applier.window_open`, `autonomy.level`.

## Files
- skills/sigma-loop/scripts/unpark.py: `report()`, `render_report()`, `report` verb in `_main`, usage line.
- tests/test_unpark_report.py (new).
- docs/decision-rulebook.md (enable steps), CHANGELOG.md (one line under Unreleased).
- No write-surface change (nothing is written); no SKILL.md change.

## Behaviour
The verdict follows the order of `applier.tick` and `open_for_park`:
never when: applier off; kind undeclared (a suggestion never acts); hard-stop kind; kind unknown,
scope_hold or owner_hold; no approved rule for kind and area; rule gesture is none (recommend only);
a person already answered this park; pair level below 3; rule due for reconfirmation; rule lacks its
own live support. Later when: no ask yet (opens on next sync), the ask is armed later or its window is
open, quota not reset, or the daily cap is reached. Otherwise now.

## Test list
1. declared kind, matching rule, level 3, ask past window: now, with rule id and gesture.
2. undeclared park: shows suggested kind, never, reason says not declared.
3. hard-stop kind (irreversible) with a would-be rule: never, hard-stop reason.
4. rule matched but ask window open: later.
5. no rule for the pair: never, no approved rule.
6. level below 3: never, level reason.
7. totals line per outcome and the counts add up; --json carries the same rows.
8. read-only: no gh write calls, no files changed under the sdlc dir.
9. usage line mentions report; applier off gives never for all.

## Risks
- Re-implementing applier logic: kept to calls of its helpers; order mirrored from tick.
- One REST read per park (linear), same cost as `list --undeclared`.
- Break-it control: remove the hard-stop check and see test 3 go red.
