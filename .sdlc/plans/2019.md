# Plan 2019: count GitHub calls by component, cost per goal, baseline

Plan sha256: pending

## Behaviour
- New `skills/sigma-loop/scripts/gh_calls.py`: `count(args)` classifies one gh argv into bucket
  `rest` (core REST), `graphql` (use gh_quota.graphql_shaped-equivalent logic, standalone), `search`
  (`gh api search/...` or `gh search`), and increments an in-memory dict keyed (hour, component, bucket).
  Counts only: no args, titles, bodies stored. Never makes a GitHub call. Never raises.
- Component = innermost `with gh_calls.component("name")` else env `SIGMA_GH_COMPONENT` else basename of sys.argv[0] sans `.py`.
- Flush: on hour change, at exit (atexit), appends one JSON line per (hour,component,bucket) to `<sdlc>/state/gh-calls.jsonl`;
  rotation at 1 MB to `.1` exactly like pick_trace._append. State dir = `SIGMA_SDLC_DIR` env, else `./.sdlc` if it exists, else no write. Write failure swallowed.
- Hooks sit at the runners: `sources._run_gh`, `gh_api._default_run`, and the gh_api shared spawners (`gh_argv` users around lines 1276-1300). Sibling modules are loaded by path, so each copy writes to the file; the report sums lines.
- `_auto_unpark_sweep` (loop.py) wraps its body in `component("auto_unpark")` so the run=None path is attributed.
- Report: `loop.py gh-calls-report <sdlc_dir> [--hours N]` prints component x bucket totals, read-only.
  Cost per goal / per lane: extend `orchestrator_context_report.py` or add `cost_by_goal` read of existing phase events (phase_report data) producing per-goal and per-lane totals, no model call; "not measured" when no data.
- Baseline: nothing fabricated. The issue gets "baseline: not measured" until a 1h 5-slot run exists.
