# Plan #1589: chain growth bounds, delta sheet, freeze

Spec: issue body (Design + Done when); epic 1583 rulings: join automatically up to 5 per chain then ask; `--no-grow` makes every addition ask; the end goal never changes. Builds on landed `chain.py` (`plan`, `questions_of`, `answer`, `run`, `resume`), `chain_spend` (parses `chain.max_added`, `chain.max_goals`), `label_drain.pull`.

## Files
- `skills/sigma-loop/scripts/chain.py`: new `_grow(...)` called from `run()` after the spend admit and before the pick; `run()` gains `no_grow` (CLI `--no-grow`) and injectable `pull` and `filed`; `render_run` prints the new lines; `resume` clears the paused/delta state it answers; the closing summary lists joined and "filed, not in the chain".
- `tests/test_chain_growth.py` (new), `CHANGELOG.md` (END of Unreleased), script-help and write-surface registries as tests demand, `docs/chain.md` only if it exists.

## Behaviour
- Each cycle re-resolves the end goal's open closure (existing `plan`). New open prerequisites of members (not in recorded members or `run.seen`, not the root) are classified: armable without a decision AND `len(joined) < chain.max_added` (default 5, from `chain_spend`) AND members+joined < `chain.max_goals`: joined through `label_drain.pull(sdlc_dir, label, ref, for_goal)`, ONE printed line, kept in `run.joined`. Needs a decision, or over a bound, or freeze (`chain.freeze: true` in config or `--no-grow`): not pulled; recorded in `run.paused` as `{prereq: [its dependents among members, transitive]}`; a delta sheet containing ONLY the new questions is printed (reuse the sheet renderer on those rows) and stored in `run.delta`; `answer` accepts the delta questions, then `resume` clears them. Pause counter `run.pauses` rises once per cycle that prints a delta sheet; when it would exceed `chain.max_reasks` (default 3, a fourth pause) the run ends `stuck` with reason `decision`.
- While something is paused the pick's skip list gets the paused dependents (independent branches continue); if the pick is then empty and members remain, STUCK(decision).
- Anything else filed from a member (not a prerequisite) never joins: `filed` (injectable; default reads nothing extra and returns the weak/outside references the plan already reports, if it exposes any, else an empty list) is listed under "filed, not in the chain" in the run output and the closing summary. PROVISIONAL (owner to ratify): detection of non-prerequisite follow-ups is limited to that source; no new GitHub search.
- End goal decomposed: its slices appear as new prerequisites and join by the same rule; the root number in the record never changes, never re-parented.
- Gate: nothing changes when no chain record exists or `run` never called; existing `test_chain_run.py` stays green with unchanged outputs when no growth is found (byte-identical `render_run` for that case).
