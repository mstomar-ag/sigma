# Plan: goal 1088, the pre-push private-term guard as a tracked, tested file
Files: tools/prepush_scan.py (new), docs/prepush-guard.md (new), tests/test_prepush_scan.py (new), docs/launch/write-surface.json only if a write-shaped call is detected, CHANGELOG untouched (bullet in /tmp/cl/1088.md).
Behaviour: git runs a pre-push hook with the remote name as argument and `local_ref local_sha remote_ref remote_sha` lines on stdin. The tool reads those lines and, per ref, scans `rev-list LOCAL --not [REMOTE_SHA] --remotes` (so a merge of the default branch adds none of the upstream commits, nor does a new branch). `--base REF` replaces `--remotes` with one ref. Each scanned commit's message and added lines are matched against the patterns file (`--patterns FILE`, else `SIGMA_PREPUSH_PATTERNS`; no default path; one case-insensitive regex per line, `#` comments and blanks skipped; a bad or empty-matching regex refused by line number). A delete push is skipped. Output states "scanned N commits, skipped M reachable from remote-tracking refs". A hit prints commit, surface, pattern line number only, never the matched text (a secret would be echoed otherwise). Exit 0 clean, 1 hit, 2 usage or patterns refusal. Read-only: it only runs git read verbs.
Install (docs): a two-line hook that execs the tool with the patterns path; the patterns file lives outside the repo; the doc ships a neutral example pattern.
## Test list
Clean push passes; planted pattern in an added line refused (red on the documented hook gesture); planted pattern in a message refused; upstream commit carrying the pattern arriving via a merge of the default branch is not scanned and a new own commit is; new branch scans only unpushed commits; delete push skipped; missing patterns file exits 2; bad regex refused by line number without echoing it; hit output carries no matched text; --help exits 0 with usage.
Risks: `--remotes` hides a commit already on any remote (accepted, already public to that remote); stale remote-tracking refs could skip a commit that never reached the default branch (doc says fetch first); hook runs under the user's git, so the tool strips GIT_DIR-style env only for its child calls it does not need, left as is.
