# Plan 1353 - classifier timeout kill: bound the post-kill read, cover interrupts
Plan sha256: (set by tool)

## Behaviour
Find the classifier subprocess call with a group kill on timeout (grep the model classifier runner used by the decision import / classify path: a Popen with start_new_session and killpg). Change: (1) after the group kill the pipe read (communicate/read) gets its own short timeout and gives up with the partial output rather than blocking; (2) a KeyboardInterrupt (BaseException) during the call kills the child group and re-raises; (3) the pidfile test waits (bounded poll) for the file instead of asserting immediately. Behaviour on the normal path is unchanged.

## Files
the module found by the grep, `CHANGELOG.md` (entry at END of Unreleased), its existing test file (pidfile test fix) and a new test for the bounded read and the interrupt.

## Test list

- interrupt raised during the wait: group killed, interrupt re-raised (red before fix).
- pidfile test no longer races.
- normal success and plain timeout paths unchanged.

## Risks
