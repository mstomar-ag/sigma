## Files
- skills/sigma-loop/scripts/feature_upkeep_pass.py: add small, injectable, individually testable functions (no network, no model):
  - `engine_env()` / runner settings: no-prompt git, no editor, `rebase.updateRefs=false`, no signing, per-command timeout. Reuse what
    the hygiene slice already put in the tree if present (look before writing).
  - `recheck_tips(read, step, max_restarts=2)`: records both tips at start, re-reads before each costly step, restarts at most twice, then outcome `moved`.

  - `classify_push_refusal(...)`: a refused push to a goal branch whose PR already merged and branch deleted is a skip with a reason.
  - `ledger_note(unit_key, outcome, sha12)`: unaddressed `note`, key `upkeep-<unit-key>`, ref `upkeep:<outcome>:<sha12>`, via `ledger.safe_append` in-process (never `loop.py note`).

## Decisions (PROVISIONAL, owner to ratify)
- The recorded cut tip drives `--onto` inside the goal rebase for active goals too; goals cut before the record existed use the legacy path.
- Findings with no real goal (scheduled pass) are written only as ledger notes and the per-unit state, never as a goal-bound filing.
- Filing notes are unaddressed (no inbox wake). Per-machine ack limitation documented in the docstring.
- A squash-landed unit that gets new commits: only commits not contained by the base are replayed (landed commits are never replayed).
- Direct commits on an already-current unit are reported as a skip reason, not rewritten.
