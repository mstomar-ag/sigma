## Design
- Landed = tip is an ancestor of the base tip (rev-list of tip not base is empty), or a supplied merged landing request into the
  base has head equal to the exact unit tip. The request source is a callable; no network call in this module.
- Landed unit: result `skipped` with reason, state outcome `current` plus both tips. Never moved.
- Git cannot answer: result `unreadable`, nothing recorded. A failing request source leaves the git answer.
- Gate closed: the decorator returns the closed result before any call (nothing spawned, read or written).
- Pick time is untouched (no new call), so the pick-time call-list pin stays as is. No new engine outcome is added.

## Test list
- gate closed (absent, false, text "true"): closed result, runner never called, no file.
- contained unit: skipped, reason landed-contained, state file with outcome current and both tips.
- unit ahead of base: not-landed, no state file.
- squash landing found by a merged request head equal to the tip.
- requests that do not prove landing: unmerged, other base, different head.
- failing request source: git answer stands.
- unanswerable git and a non-sha answer: unreadable, nothing recorded.
- three break-it controls: inverted contained test, dropped head comparison, unreadable read as landed.
- slice-1 pins: registered entry point has a closed-gate driver (no process, model, network, file); note claim pin; static guard.
