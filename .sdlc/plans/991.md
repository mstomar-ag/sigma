## Behaviour
- `read_events(sdlc_dir)` returns the park-bearing dicts from `.sdlc/events/*.jsonl`; malformed lines are skipped; a missing directory gives an empty list.
- `mix_from_events(events)` counts `kind == park` events by `reason_class` (missing class counts as unknown).
- `mix_from_comments(comments)` takes strings or dicts with a body; only comments starting with a Sigma park or fail prefix are counted, classified with `loop._reason_class` on the text after the prefix.
- `census(issues, config)` considers issues carrying the configured needs-confirmation label. Precedence: scope marker, ownership flag (both gate holds, never AI), follow-up label, then kit-filed other, then human-typed. Keys are always present.
- CLI `park_mix.py report <sdlc_dir>` prints JSON of the event mix; it opens files only for reading.
