## Decisions
- No new config keys: adding schema keys would move the pinned schema table, the shipped template and the gate tests for
  numbers nobody has measured. Limits and caps are request fields of the library with PROVISIONAL defaults (the part A
  numbers: 6 files, 20 hunks, 800 conflict lines, 8 stops, 2 attempts); the caller (the pass) supplies caps. Owner call.
- The resolver runs in a plain export of the stopped tree OUTSIDE the repository (no .git, no agent files); the engine, not
  the model, writes resolved content back and runs `git add`. Confinement is the launcher's existing post-run diff check.
- Every flag beyond the confirmed table stays refused; the model flags are UNVERIFIED; a fake `claude` is the only process.
- Non-Claude hosts park (D-2): the module refuses unless the request names the claude route.
- Chat door (D-23): gate closed => byte-identical prompt and timeout; gate open => prompt says the engine owns resolution,
  the session still reports and never resolves, and the unit lock hold is bounded (PROVISIONAL 30 minutes, owner call).
- The drill variant (D-24) is run once against the fake: a hostile hunk that makes the fake edit a file outside the conflicted
  set is discarded, parked and still charged.

## Behaviour
1. `eligibility(...)` parks, with a code, on: protected path, structural stop (a stage missing), more files/hunks/lines than
   the limits, a merge-commit stop, more stops than the limit, attempts exhausted.
2. `resolve_stop(...)`: eligible -> export -> launch -> engine writes back (refuses leftover markers) -> `git add` -> stamp
   (level 2) -> authorship check -> `rebase --continue` (no hooks). Any refusal returns a code and the charge.
3. After the replay: `prove` (existing) -> `review_gate` (approve required; block/refused/closed parks) -> existing atomic
   backup push. Record gets level 2, model, cost, verdict, route.
4. Attempts: `state/upkeep/level2/<unit>.json`, bounded list, each attempt with outcome and charge, written before the run.
5. Gate closed: no Level 2 code path executes; `_level1_options` returns no `level2`; a test compares the report of a
   conflicted pass with the gate closed to the pre-change shape.
