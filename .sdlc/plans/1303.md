# Plan 1303: a park whose label write fails must not exit 0

## Goal
`loop.py record <N> parked "<why>" --qkind <kind>` under GraphQL exhaustion posted the comment, printed
"label write failed ... continuing" and exited 0, leaving the issue `sdlc:goal` (pickable, absent from
the unpark list). For the PARK transition only: fall back to REST label writes when the GraphQL swap
fails; if that also fails, `record ... parked` exits non-zero with one clear message.

## Design (PROVISIONAL choices marked)
- `GitHubSource._offboard(goal, comment, rest_fallback=False)` returns whether the label write landed.
  Only `park()` passes `rest_fallback=True`; `fail()` and every other transition are untouched.
- Fallback reuses the existing REST helpers `_issue_add_labels` / `_issue_remove_label` (already in
  docs/launch/write-surface.json), so no new write call site is added. Add parked first, then remove
  goal / in-progress / blocked (a 404 on remove is a no-op), mirroring the swap's add-first order.
- `park()` returns the landed flag (True/False; None for an early-return foreign issue).
- `loop._record` gets an optional `park_failed` list; when the source's `park()` returns exactly False it
  appends once. All local writes (ledger, cursor, action log) still happen. Only the CLI `record` verb
  passes it, prints one stderr line, and exits 1. `run_loop` callers are unchanged (PROVISIONAL: the
  autonomous loop keeps park-and-continue; the reconciler path is not changed).
- PROVISIONAL: no extra retries beyond the existing swap retries.

## Test list
1. Control on the documented gesture (subprocess `loop.py record N parked why --qkind k`, PATH fake gh,
   GraphQL always rate-limited, REST healthy): issue ends parked, not goal; exit 0. Red before (issue stays goal).
2. Both GraphQL and REST label writes fail: exit non-zero, one clear message, local ledger still written.
3. No-failure path: GraphQL healthy -> exit 0, no REST label write attempted, no new message.
4. `fail()` transition unchanged: no REST fallback attempted on swap failure.
