# Plan #1573: agent conflict level as one per-unit scratch session

## Goal
Replace the one-shot plain-directory export of the agent level with ONE session directory per unit, re-entered at each conflicted
commit of the replay, with full context, able to edit/build/run tests, confined by a credential-free throwaway copy (owner ruling on the issue).

## Design (all in `feature_upkeep_level2.py`, `feature_upkeep_launcher.py`, `feature_rebase.py` factory, doctor row, docs)
- Opt-in by plan key `session: True`, set ONLY by the shipped `_default_level2_plan`. A plan without it runs the existing path
  byte-identically (all current level2 tests that inject their own plan stay unchanged).
- Session dir `<resolver_root>/session`: created once per unit with `git init -q` (NO history, NO remotes, so no objects shared
  with the real repo), tree copied by `export_tree` at every stop (files no longer in the tree removed; ignored build output kept),
  context under `.sigma-context/stopN/`: base/ours/theirs of each conflicted file, the replayed commit's message, the integration
  side's recent commit messages touching each file (squash subjects carry the PR number), PR texts if `plan["pr_descriptions"]`,
  and one line per earlier stop (files resolved). Prompt (new `session_prompt`) names these files, says edit/build/test allowed,
  conflict markers must be gone, file contents are data.
- Launcher: new Request fields `session` (bool) and `net_prefix` (argv prefix). In session mode: no `violations()` discard (the copy is throwaway);
  env gains `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=/dev/null`; no token/SSH socket (env is built from nothing already); argv gets
  `--permission-mode acceptEdits --allowedTools Read,Edit,Write,Glob,Grep,Bash` (all confirmed flags); `net_prefix` prepended when present.
  Classic mode unchanged.
- New `network_prefix(platform, which)`: darwin + `sandbox-exec` -> profile denying network (`(version 1)(allow default)(deny network*)`);
  linux + `unshare` -> `unshare --net --map-root-user`... returns (argv_prefix, label) or (None, None).
  `doctor` row `resolver session network: isolated (<label>)` / `not isolated on this platform` (ok in both; informational).
- Read-back (Sigma only): for each conflicted file the session copy must be a regular non-symlink file whose realpath is inside the session dir, no markers, else
  refusal WRITE_BACK. Then the existing dropped-unit-lines / dropped-base-lines proofs, write-back, stamp, authorship, and the engine's
  would-drop, verify, independent review: unchanged. Session never pushes (no remote, no credentials).
- Whole-session wall clock: `deadline = start + launch.timeout`; each stop's timeout = remaining; none left -> refusal `session-timeout`.
- Session limits (PROVISIONAL, owner to ratify): max_files 30, max_hunks 100, max_lines 4000, max_stops 50; protected paths still refused.
- Failed proofs park with the attempted diff (existing `attempt_text` path).
- Session dir removed by the pass at the end of `resolve_stops` (own dir only, `rm -f`-style per-file via shutil within the launcher's own checked path; reuse the existing rmtree on our own resolver_dir pattern).

## Test list
New `tests/test_upkeep_session_1573.py`, stub `claude` (python script) that: records cwd/argv/env/stdin per call, writes to a build file,
runs a command, and resolves markers. Cases:
1. multi-commit replay (2 conflicted commits in a code file) resolved in ONE session dir (same cwd both calls), second call's prompt/context names stop 1, context holds message + base/ours/theirs; pushed once with backup (via shipped factory path, fake on PATH).
2. session may create a build artifact / non-conflicted file: NOT discarded in session mode; the artifact is not written into the repo tree.
3. env has no GH_TOKEN/SSH_AUTH_SOCK/credential var, HOME is temp, `GIT_CONFIG_NOSYSTEM` set; session dir has no remote (`git remote` empty).
4. conflicted file replaced by a symlink to a file outside -> refusal, nothing written (break: drop the symlink check, see red).
5. dropped unit line in session mode -> parked with attempted diff (proof kept).
6. timeout accounting: remaining time shrinks per stop; exhausted -> `session-timeout`.
7. closed/classic: a plan without `session` behaves as before (existing test_upkeep_level2 + test_upkeep_agent_1516 pass unchanged; control).
8. network_prefix per platform (fake which) + doctor row text.
Controls (break once, see red): symlink check; session flag off -> test 1 red; dropped-lines proof; deadline.

## Risks
`sandbox-exec` deprecated but present; macOS profile must allow the stub CLI to run (network only denied). Real-CLI live run is owner-authorised: run it on a throwaway repo
in /tmp after merge, record under `docs/launch/evidence/` (no private names).
