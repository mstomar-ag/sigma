## Behaviour
- `CLASSES`: six default-on classes (spend, destroy, rewrite_history, production_change, send_outside, access_secrets) and two default-off (tamper_oversight, unvetted_execution), each toggled by `hard_stops.classes.<name>`.
- `classify` returns a Result of class, pattern id and a scrubbed quote. Gate: unless `hard_stops.enabled` is exactly true the result is None (closed, no work done). Config may be the rubric block or a dict holding it.
- A matched class wins; otherwise a non-string input, a shell parse failure, or any detector exception gives "cannot-tell". Never None on error.
- Own carve-out: a force push whose target branch (from context or parsed from the command) is own yields None with pattern id `own-branch`.
- `raise_to(prior, declared)`: ordering None < cannot-tell < a class; returns the higher; unknown values are treated as cannot-tell.
- `is_own`: prefix list (default `sdlc/`), or `feature/<unit>` for a unit in the registry mapping, key folded with the registry module's `unit_key`; an unreadable registry means not own.
- `register_class` validates name, callable detector, no clash; `classify` and `raise_to` refuse a class not in the registry.
- `is_hardstop_kind`: default kinds `["irreversible"]` plus configured; any record with a `hardstop_class` is a hard-stop kind. Not gated by `enabled` (fixed safety rule).
- Quote: matched span, run through the shared scrubber, then flag-value and long-opaque-token redaction, capped at 120 characters.

## Test list
- each class has a matching pattern; parse error is cannot-tell; declared class never lowers; own lease push not classified; quote is scrubbed; module imports no network or subprocess; unregistered class refused; irreversible kind is hardstop; record with class is hardstop.
- extra: gate closed gives None; optional class off by default; extra patterns raise only.
- Controls: break max-merge, break the error branch, break the scrub, each seen red once.

## Risks

- Config shape (block versus whole config) is provisional until the wiring slice.
