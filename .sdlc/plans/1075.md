## Behaviour
Killed job: next tick, record running + lock free -> done/failed, unit counted failed, one unaddressed note. Live job: unchanged.
Budget: an expired budget stops measurement mid-unit; cursor stays before that unit. Gate closed: untouched (decorator first).

## Test list
- killed job gets a failed note once; a held lock is a live job; budget raise inside a unit stops the loop with cursor;
  make_measure raises before git when expired.

## Risks
A job just spawned and not yet locked, with a stale running record, is closed early: it is a dead record either way.
