# Plan 1937: the watcher honours watch.stop during its sleep

Files: skills/sigma-loop/scripts/watch_daemon.py (new `sleep_unless_stopped`, `STOP_POLL_SECONDS` = 5), docs/upgrading.md (bound stated), CHANGELOG.md, tests/test_watch_stop_during_sleep_1937.py.

Behaviour: the sleep between ticks wakes every 5 seconds and returns at once when `state/watch.stop` is a file; the loop's own top-of-loop check then logs and exits as before. Bound: about 5 seconds plus a tick already running (each call capped by SIGMA_WATCH_CALL_TIMEOUT).

## Test list
- mid-sleep stop ends the sleep within one poll (red when the in-sleep check is removed)
- no stop: the whole interval is slept in polls
- existing stop returns before sleeping
- default poll <= 5 and the loop uses the helper (red when plain sleep is restored)

Risks: a stat every 5 s per watcher (negligible); SLEEP_SCALE=0 still skips the sleep.
