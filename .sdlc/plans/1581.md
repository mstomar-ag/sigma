## Behaviour
- Kind = name up to first `:` or `/`, else whole name. `label_drain.kinds` (exact name -> kind) overrides; non-dict map, non-string values or empty ignored.
- History: when records gate (`decision_record.enabled`) is open, `plan` adds per question `history` ("last time on this label: <choice>" from records of the same scope+qkind; else counts per answer from records whose area is `label-kind:<kind>`). `render_plan` prints it only when present. Gate closed: plan dict and rendered text byte-identical to before (no new keys).
- Recommendation: rules part open -> `rulebook.prefill(sdlc_dir, "label_set", "label-kind:<kind>", options, config)`; the option is listed first and marked recommended (`recommendation` key on the question: {rule_id, option}; option text itself unchanged so `_bank_match` still accepts). Never applied automatically. Spend (`irreversible`) questions never get a recommendation and `autonomy` level stays capped at 2 (existing hard-stop; test with 400 answers).
- Answer record for label_set: `rule_id` (top level), `shown` True, `accepted` = chosen == recommended option, via the same fields `unpark._comment_decision` uses.
- Level: ten `label_set` answers in one kind -> level 1 via existing `autonomy.level`; autonomy.py unchanged. Free-text answers do not count (existing).
- Public visibility: scope holds a hash; label name appears in no record file nor comment text (comment text "Run label X" must also drop the name under public).
