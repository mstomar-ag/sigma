## Design contract
- **ONE sdlc dir:** the MAIN checkout's `.sdlc`, resolved from inside a goal worktree via git-common-dir exactly as `north_star.project_root` does (as `diff_revert.scratch_dir` also assumes), used for BOTH the work record and the scratch. Stem: `str(goal).replace("/", "_").replace("..", "_")` after stripping a trailing `.md` (copy of `work.stem` behaviour), so `1635.md` and `1635` share one stem and one scratch. Tests run the CLI from inside the goal worktree.
- **Work record (no `work.py` import):** read `<sdlc>/state/work/<stem>.json` directly (`json.loads`), check `state.unsafe_goal_reason(stem)` first. Empty `base`, empty `remote`, `base_resolved: false`, absent or unreadable record: every metric `unmeasured` (reason on stderr), no process. ref = `<remote>/<base>`.
- **git helper (own, not `diff_revert._git`):** `_git(root, argv)` runs `git` with `bounded_run.unattended_env()`, `GIT_DIR`/`GIT_WORK_TREE` removed, `LC_ALL=C`, stdin closed, stdout and stderr separate, a timeout. Returns the 3-tuple (code, stdout, stderr). `diff_revert._reclaim_stale` and `cleanup` take `git_cmd` returning (code, out), so they are ALWAYS passed an adapter `_git2(root, argv)` that returns (code, stdout + stderr) (never the 3-tuple, never omitted: omitted would use `diff_revert._git`, which inherits GIT_DIR and skips `unattended_env`). Used for merge-base, ls-tree, cat-file, status, diff, worktree add.
- **Config at the fork:** `git merge-base HEAD <ref>`, then `git ls-tree <fork> -- .sdlc/config.json`: exit 0 and empty output = absent (`no metrics configured`, exit 0; Sigma's own repo, gitignored file: self-hosting measures nothing, stated in the doc); exit 128 or other = `unreachable`; the entry must be mode 100644 or 100755 and type blob, anything else (symlink, directory, gitlink) = `unreachable`, every metric `unmeasured`, no process. Present: `git cat-file blob <sha>`, decode `utf-8-sig`. Never the head's file. Malformed `quality` block: stderr `quality_delta.py: REFUSED [bad-metric] metrics[<i>]: <detail>`, exit 2, empty stdout.
- **Entry schema:** `{name, command (non-empty list of strings), direction lower|higher, scope repo|changed-files, required (bool, optional), timeout_seconds (optional)}`; block-level `memory_floor_fraction`, `env_drop` (list of names).
- **Dirty goal:** `git status --porcelain --untracked-files=normal -- . ':(exclude).sdlc'` in the goal worktree; non-empty means the head side is `unmeasured` (stderr reason: uncommitted work is not measured) so a false `same` cannot print. Modified or staged tracked files and untracked source files OUTSIDE `.sdlc` count as dirty (the head scratch is committed HEAD, so they are not measured); untracked `.sdlc` plan/research/acceptance copies, present in the normal flow until commit, do NOT. Head measured = committed HEAD, in its own scratch.
- **Header line (C-1):** first stdout line `base=<fork-sha> head=<head-sha>`, before the metric lines; `no metrics configured` stays the only line in that case. With no fork or no record it prints `base=- head=<sha or ->` (reason on stderr); the normal form is likewise `base=<sha> head=<sha>`. (R-02 binds waivers to the head SHA.)
- **Scratch:** `<sdlc>/state/quality_delta/<stem>-base` and `-head`, each `worktree add --detach` at fork and at HEAD; owner marker (`diff_revert._owner_path`) written BEFORE creating anything; reclaim via `diff_revert._reclaim_stale`/`cleanup`/`_pid_alive` loaded by path; both removed in `finally`; assert the path is under `<sdlc>/state/quality_delta/` before cleanup. Per goal, so parallel goals never collide.
- **Runner:** `bounded_run.run_group(argv, scratch, timeout, env=filtered, merge=False, max_out_bytes=1 MiB, term_grace=2)`. Non-OK outcome, `truncated`, or no parseable number: `unmeasured`.
- **Env filter** `drop_credentials(env, extra)`, case-insensitive: exact `GH_TOKEN`, `GITHUB_TOKEN`, `SSH_AUTH_SOCK`; suffixes `_TOKEN`, `_SECRET`, `_PASSWORD`, `_PASSWD`, `_PASS`, `_PAT`, `_API_KEY`, `_KEY`, `_CREDENTIALS`; substring `AUTHTOKEN`; prefixes `AWS_`, `ANTHROPIC_`, `OPENAI_`; plus `quality.env_drop`. Denylist: unknown credential names can still survive and `quality.env_drop` is the lever (doc says so). HOME stays, so `~/.config/gh`, `~/.netrc`, `~/.ssh` remain readable by a metric command; the doc says so.
- **changed-files:** `git diff --name-only -z --no-renames <fork> HEAD`, restricted to paths present at both commits; the NUL list is written to `.sigma-quality-files` at the root of EACH scratch worktree (untracked there, removed with the worktree by `diff_revert.cleanup`), and env `SIGMA_QUALITY_FILES` holds that absolute path, never argv. We never unlink it ourselves (avoids a scanner `fs-remove`). Empty list = `unmeasured`. `repo` scope: variable unset. Nothing is written outside the scratch dirs.
- **Number grammar:** last non-empty stdout line must fullmatch `^[+-]?\d+(\.\d+)?([eE][+-]?\d{1,3})?$` with `re.ASCII`, then `Decimal`, finite. Rejects underscores, non-ASCII digits, `nan`, `inf`, `1e999`, empty, multiple tokens. Delta = head - base printed with `format(d, "f")` (no scientific notation); equal = `same`.
- **Probe:** `probe_memory()` returns (available, total) or None. Linux `/proc/meminfo` MemAvailable (host figures, NOT cgroup limits: documented); macOS `vm_stat` run with a timeout, header must name the page size, free+inactive+speculative pages x page size; total from `os.sysconf`. Floor = 15 percent of total by default (25 percent was marginal: a 24 GB Mac reads about 30 percent free+inactive+speculative; 15 percent is a judgement, flagged for the owner), overridable by `quality.memory_floor_fraction` (0 < f <= 0.9, else refusal). Probed once up front and again before EACH command; if it dips mid-run, that metric and every later one are `unmeasured` (already-measured metrics keep their values; doc says so); racy between probe and spawn (named ceiling). Windows or `group_refusal()`: exit 2 `not supported here`. Probe injectable in `measure()`.
- **Timeouts:** per command `timeout_seconds` default 300, max 3600. Wall bound per command: T + term_grace (2 s) + git time; run <= 2 x sum(T + grace) + git. A grandchild that calls `setsid` leaves the process group and escapes the kill: documented, covered by a test, not fixed.
- Writes only under `.sdlc/state/quality_delta/`; no network, no gh, no signals except through `run_group`.

## Scale (bounds, not measurements)
Runs = 2 x M, serial, one process at a time per goal; wall <= 2 x M x (T + 2 s) + git, T <= 3600. 10x metrics: 10x wall, same memory. 100x commits: checkout is O(tree size), merge-base a history walk; neither scales with commit count. `repo` scope is the ceiling; changed-files bounds by the diff. Output <= 1 MiB per command (peak about 3x). Two parallel goals run two commands at once; guarded only by the racy per-command probe. No unbounded growth: scratch and owners removed in `finally`; a crash leaves them for dead-pid reclaim. Real run time unmeasured until Implement.

## Recovery
Crash, reboot or SIGKILL mid-run: lifeline stops the metric group; next run reclaims by dead pid (lever: rerun, or delete `.sdlc/state/quality_delta/<goal>-*`; no tracked root files involved). Live sibling: abstain. Hung command: group killed at its timeout. Git outage: `unmeasured`. Idempotent rerun.
